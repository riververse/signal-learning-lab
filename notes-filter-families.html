dB：幅值与功率分开算

dB（分贝）是对数形式的比值，不是电压、压力或频率的单位。设同一频率稳态正弦的输入幅值为 A、输出幅值为 B，则幅值增益是 B/A；不要拿某一拍恰好接近零的样本值相除。

GdB = 20 log10(B/A)
B/A = 10GdB/20

功率比改用 10 log10(Pout/Pin)。只有功率与幅值平方成正比、比较条件一致（例如同阻抗）时，才能把两种计算直接对应。

增益幅值比例含义
0 dB1幅值不变
−1 dB约 0.8913幅值保留约 89.1%
−3.0103 dB1/√2 ≈ 0.7071半功率，不是半幅值
−6.0206 dB0.5半幅值，功率约为 1/4
−40 dB0.01幅值剩百分之一

“截止”不一定就是 −3 dB。半功率的精确值是 −3.0102999566 dB，常简称 −3 dB。不同设计函数对边界频率的定义不同，必须先读定义，再比较参数。

相位：延迟不等于衰减

幅频响应回答“每个频率变成多大”，相频响应回答“每个频率挪动多少相位”。若所有成分都只延迟同一段时间 τ，那么相位随频率是一条斜线：

φ(f) = −2πfτ　（φ 用 rad，f 用 Hz，τ 用 s）
τg(f) = −(1/2π) dφ/df　（单位 s）

群延迟描述相位曲线的局部斜率。用数字角频率 ω（rad/sample）作横轴时，τg(ω) = −dφ/dω 的单位是样本；再除以采样率 fs 才是秒。比较曲线需展开相位，不能把 ±π 的显示跳变当作突然改变的物理延迟。

例如 fs = 1000 Hz，延迟 5 个样本就是 5 ms。10 Hz 成分相移 −18°，20 Hz 成分相移 −36°；角度不同，但时间延迟相同。

长度 L 的实系数对称或反对称 FIR 可具有线性相位，群延迟为 (L−1)/2 个样本。FIR 不自动等于线性相位，线性相位也不等于零延迟。响应零点处相位和群延迟不能按普通非零点解释。只有幅度也按所需比例保留时，多频信号才只是整体延迟；单有线性相位并不能保证波形幅度不变。

这里记录已讲过的概念。阶跃、振铃、不同家族的延迟曲线和更深的动态比较仍留在下一课，不提前记作已完成。

先写完整指标，再比较家族

低通/高通说的是保留哪些频率；FIR/IIR 说的是冲激响应的持续长度；巴特沃斯、切比雪夫和椭圆说的是一种响应设计取舍。它们不是互相替代的一组分类。

家族幅频形状不能据此推断
Butterworth 巴特沃斯通带最大平坦，幅度单调下降不是整个通带增益都恰好等于 1
Chebyshev I 切比雪夫 I 型允许通带等波纹，阻带单调纹波不是随机噪声，也不是一定更差
Chebyshev II 切比雪夫 II 型通带单调，阻带等波纹边界参数不与 I 型使用相同含义
Elliptic 椭圆通带和阻带均允许等波纹低阶不保证延迟、过冲和数值误差都更小

一个完整的低通设计任务

fs = 1000 Hz；通带 0–50 Hz；阻带 100–500 Hz
通带最大损失 Ap = 1 dB；阻带最小衰减 As = 40 dB

50–100 Hz 是允许响应逐渐下降的过渡带。通带要求幅值不低于 10−1/20 ≈ 0.8913；阻带要求幅值不高于 10−40/20 = 0.01。只说“50 Hz 低通”无法表达这两个要求。

数字低通设计最低阶 N设计函数 Wn / HzWn 的含义
Butterworth854.32426352半功率频率
Chebyshev I550开始跌出 −Ap 的通带边界
Chebyshev II588.53250447首次达到 −As 的边界
Elliptic450开始跌出 −Ap 的通带边界

这些阶数按同一完整数字指标，用 SciPy 1.17.0 阶数选择与设计函数复核，并用频率网格检查通带和阻带；不是实物测量。高阶实现通常分为二阶节（SOS），上述阶数分别需 4、3、3、2 行 SOS；奇数阶含一个一阶节。

巴特沃斯的阶数从哪里来？

模拟原型满足 |H(jΩ)|² = 1/[1+(Ω/Ωc)2N]。先把通带、阻带的容许损失代入，再消去 Ωc，得到最低阶条件。数字双线性设计须先预畸变，不能直接拿 Hz 比值冒充精确模拟比值：

Ωp = 2fs tan(πfp/fs)
Ωst = 2fs tan(πfst/fs)
N ≥ log[(10As/10−1)/(10Ap/10−1)] / [2 log(Ωst/Ωp)]

最后向上取整，并求合适的临界频率。这里 Ω 单位 rad/s，f 单位 Hz，fst 表示阻带边界，避免与采样率 fs 混淆。比较家族时仍需共同核对延迟、状态范围、定点精度和计算预算，而不只比较 N。

从差分方程看到零极点

先用熟悉的 EMA：y[n] = 0.2x[n] + 0.8y[n−1]。在零初始状态下，延迟一个样本对应 z−1：

H(z) = Y(z)/X(z) = 0.2 / (1−0.8z−1) = 0.2z/(z−0.8)

分子为零的 z = 0 是零点，分母为零的 z = 0.8 是极点。z 是复变量，不是 Hz；分析频率响应时，沿单位圆取 z = ej2πf/fs。极点与零点的位置共同决定响应形状。

0.8n 会衰减，1.05n 会增长，这给出稳定性的直觉。对因果、有理、约去公共因子后的离散传递函数，BIBO 稳定要求所有极点严格在单位圆内。单位圆上的极点不能按“差不多小于 1”处理；相消的模型仍需检查实际内部状态和有限精度。

固定、有限个、有限大小系数的 FIR 对有界输入输出有界；不要把“递推实现”或是否能写出某个分母形式，当成判断 FIR 稳定性的捷径。实际程序还可能因溢出、索引错误或状态初始化而失败。

二阶巴特沃斯：算到可执行系数

先做一个可复算的教学例子：fs = 1000 Hz，二阶低通半功率频率 fc = 50 Hz。它不是上一节的最低阶完整设计，只是把一个二阶节算清楚。条件为 0 < fc < fs/2，滤波更新必须以这个实际采样率运行。

从模拟原型到数字系数

H(s) = Ωc² / (s² + √2 Ωcs + Ωc²)
s = 2fs(1−z−1)/(1+z−1)
Ωc = 2fs tan(πfc/fs)

双线性变换把模拟频率轴映射到数字单位圆，但频率映射不是线性的。预畸变先调整 Ωc，使数字结果真正落在指定 fc。这里的 s 是拉普拉斯复变量，不是采样编号。

K = tan(πfc/fs)；D = 1 + √2K + K²
b₀ = b₂ = K²/D；b₁ = 2K²/D
a₁ = 2(K²−1)/D；a₂ = (1−√2K+K²)/D

分母已归一化为 a₀ = 1。本例算得：

b = [0.0200833655642, 0.0401667311284, 0.0200833655642]
a = [1, −1.56101807580, 0.641351538058]

把系数放回差分方程，别把符号翻两次

H(z) = (b₀+b₁z−1+b₂z−2) / (1+a₁z−1+a₂z−2)
y[n] = b₀x[n]+b₁x[n−1]+b₂x[n−2] − a₁y[n−1] − a₂y[n−2]

a₁ 本身是负数，所以本例第一项反馈实际是 +1.561018…y[n−1]。移项的减号与系数的负号各出现一次。不同库可能使用相反的反馈系数存储约定，不能照抄数组而不核对方程。

// 合成教学伪代码：每个通道各自保存 x1,x2,y1,y2；这里按零状态启动。
y = b0*x + b1*x1 + b2*x2 - a1*y1 - a2*y2;
x2 = x1; x1 = x;
y2 = y1; y1 = y;

先算输出再移动历史，旧状态才不会被提前覆盖。正切和系数设计放在初始化/重新设计阶段，不是每采一个样本都重新求一遍。工程上还要决定启动策略、状态共享边界、数值类型和溢出保护；这里未在硬件运行。

独立检查：不够衰减怎么办

当前待验证目标：从指标判断，而不是记住某个家族“更好”。请先写答案，再展开自查；本页不自动判分，也不记录为已经独立答对。

  1. 输入 100 Hz 正弦幅值为 2 V，使用上面的二阶滤波器。稳态输出幅值约多少？若要求至少 40 dB 衰减，允许输出最多多少？
  2. 现在只知道有用信号在 0–20 Hz、干扰在 100 Hz。能否唯一决定“加阶数”还是“降低截止”？还缺哪些指标？
  3. 若改成完整要求：0–50 Hz 最大损失 1 dB、100–500 Hz 最少衰减 40 dB，保持二阶且只降低截止频率是否足够？写出下一步验证方法。
  4. 为什么椭圆最低阶更小，不能推出它必然同时有更小延迟、更少过冲和更好的数值鲁棒性？
完成后展开：核对幅值与重新设计思路

1. 输出约 2 × 0.231178 = 0.462356 V；40 dB 衰减允许最多 2 × 0.01 = 0.02 V，所以不合格。

2. 不能唯一决定。还缺通带允许损失、整个阻带要求、允许延迟/过冲及实现资源。降低截止可加强抑制，却也可能伤害有用信号；增加阶数也可能可行，不应被一概排除。保持 Butterworth 的半功率频率 50 Hz，7 阶在 100 Hz 已约衰减 43.69 dB，但 50 Hz 仍损失 3.0103 dB。

3. 固定二阶时，满足 100 Hz 至少 40 dB 衰减要求 fc ≤ 10.3391 Hz；满足 50 Hz 至多 1 dB 损失却要求 fc ≥ 69.5473 Hz，两条件没有交集。应把完整指标交给阶数选择，再设计并检查整个频带。上文 8 阶、Wn ≈ 54.3243 Hz 的巴特沃斯就是一个可行数字设计，而不是把半功率点强行固定在 50 Hz。

4. 幅频指标不包含所有时间域与有限精度代价。还需比较群延迟、阶跃响应、二阶节内部峰值和量化后的极点/响应；这些不能靠家族名称推断。

轻量复习：−6 dB 是只剩 6% 吗？

不是。幅值比例 10−6/20 ≈ 0.5012，约剩一半。精确半幅值对应 −6.0206 dB。负 dB 表示比例小于 1，并不是“负的幅值”。
