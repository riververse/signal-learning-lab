两个问题，一条阅读路线

先回答：IIR 和 FIR 是什么？再回答：低通、高通、带通怎么区分，怎样由目标频率得到系数？

最短答案是：FIR / IIR 说的是一次冲激的影响能持续多久；低通 / 高通 / 带通说的是哪些频率容易通过。这是两种不同的分类。

本页定位

讲解已整理；是否能独立使用，留给最后的自测确认。先用最简单的滑动平均和指数平滑建立直觉，再把它们放回 FIR、IIR 两大家族。

  1. 一次输入，逐拍追踪输出。
  2. 看清每个样本、每个历史输出前面的权重。
  3. 把采样率、截止频率和衰减要求连起来。

记号统一：n 是采样编号；x[n] 是输入；y[n] 是输出；fs 是采样率，f、fc 是信号频率、截止频率，单位都是 Hz。M 表示 FIR 的抽头数（这里等于平均点数），不是频率。α 和本页各权重无量纲；输出与输入同单位。

打一拍，看影响何时结束

先给输入 8，然后一直给 0：x = [8, 0, 0, …]。它是幅值为 8 的离散冲激，输出是单位冲激响应的 8 倍。

约定很关键：所有过去输入、滤波器状态都从 0 开始。4 点平均始终除以 4，不按“已收到几个数”改分母；指数平滑也不把首个样本直接赋给输出。

FIR · 4 点滑动平均

y[n] = (x[n] + x[n−1]
+ x[n−2] + x[n−3]) / 4

输出：2，2，2，2，0，0，…
那个 8 离开 4 点窗口后，影响就结束。

IIR · 指数平滑

y[n] = α x[n]
+ (1−α) y[n−1]

α = 0.5 时输出：4，2，1，0.5，0.25，…
每次把上一次结果再乘 0.5，理论上一直有尾巴。

对这里的固定系数线性时不变滤波器，FIR = finite impulse response，有限冲激响应；IIR = infinite impulse response，无限冲激响应。“无限”指理想数学中的持续长度，不表示数值越来越大，也不表示要存无限个样本。实际有限精度会舍入，极小尾巴也可能下溢到 0。

为什么首页刚启动时，可能不会出现这串数？

首页为了减少启动偏差，把指数平滑的首个输出设为首个测量，并让滑动平均按当前已有样本数求平均。那是工程启动策略。本节用零初始状态、固定分母观察冲激响应，不能把两套初始化混着算。

如果 α = 1，公式变成 y[n] = x[n]，尾巴消失，是一个一抽头 FIR 的退化情形。所以“这个公式通常作为 IIR 使用”也要看实际系数。

递推计算，也可能仍然是 FIR

S[n] = S[n−1] + x[n] − x[n−M]
y[n] = S[n] / M

保存窗口总和 S，每次加新值、减最旧值。虽然计算过程用了上一次的 S，结果仍等于最近 M 个输入的平均。旧样本过 M 拍后被抵消，仍是 FIR。

不要用“代码里有没有递推”分类。上式在一致初始化和精确算术下等价；实际浮点累计可能缓慢漂移，整数实现要防溢出。必要时从窗口重新求和。

系数不是只有 α 和窗口

一般 FIR：M 个输入，M 个权重

y[n] = b₀x[n] + b₁x[n−1]
+ … + bM−1x[n−M+1]

M 是抽头数，b₀ 到 bM−1 才是系数；最高非零延迟为 M−1 时，阶数为 M−1。只有等权滑动平均的系数全是 1/M。

[0.5, 0.5]

两个相近输入会相加；正负交替会抵消。偏向低通。

[0.5, −0.5]

两个相近输入会相减；恒定输入变为 0。偏向高通。

同样都是 2 个抽头，效果不同。还要区分“平均窗口长度 M”和“FIR 设计用的窗函数”：Hamming 等窗函数是在设计时修整一整组权重，不能用一个平均点数代替。

一般 IIR：输入权重 + 历史输出权重

y[n] = b₀x[n] + b₁x[n−1] + …
− a₁y[n−1] − a₂y[n−2] − …

这里采用 a₀ = 1 的归一化约定，反馈项前写减号。指数平滑对应 b₀ = α、a₁ = −(1−α)，所以只用一个 α 就能确定其余权重；更高阶 IIR 通常需要多组 a、b，常按二阶节实现。

“IIR 的系数就是 α、FIR 的系数就是窗口大小”只描述了两个入门特例。一般设计必须给出采样率、通带、阻带、允许衰减或纹波，再选结构、阶数和整组系数。单给一个截止频率，通常没有唯一答案。

频率类型与实现分类分开看

  • 低通：低频较容易保留，高频较强衰减。适合慢变化显示；也会削弱真正的快速变化。
  • 高通：削弱直流和慢漂移，保留较快变化。输出通常不再代表完整的绝对压力。
  • 带通：重点保留一个频带，削弱两侧频率。例如观察某段振动。

FIR 和 IIR 都可以设计成这些频率类型。滑动平均和本页指数平滑恰好都是低通实例；不能把 FIR 等同于低通，也不能把 IIR 等同于高通。

幅频响应 |H(f)| 表示：输入某个频率的正弦波，进入稳态后，输出幅度 / 输入幅度。幅度比 1 是不变，0.1 是剩 10%。相位变化是另一件事。

幅度比 = 1 / √2 ≈ 0.7071
20 log₁₀(1/√2) ≈ −3.0103 dB

本页把这个半功率位置简称“−3 dB 截止频率”。它不是到此完全截断，也不是所有设计工具都用同一个“截止”定义。设计前要核对定义。

以下频率关系都依赖采样率。保持同一组系数，fs 加倍，对应的物理频率也加倍。采样后的数字滤波不能把已经混叠到一起的频率重新分开。

从 10 Hz 算到 α 与实际衰减

要求：每秒采样 1000 次，用一阶指数平滑，希望数字半功率截止频率为 10 Hz。先明确结构，再算系数。

fs = 1000 Hz，fc = 10 Hz
d = 2 sin²(π fc/fs)
α = √(d² + 2d) − d
α ≈ 0.06087923

d = 1 − cos(2πfc/fs) 是等价写法。三角函数的角度用弧度；fc/fs 没有单位。这里采用精确的离散时间幅频关系。

y[n] ≈ 0.06087923 x[n]
+ 0.93912077 y[n−1]

一次只接收约 6.09% 的新输入。之后不能只看“α 算对了”，还要核对想保留的信号与想抑制的干扰。

1 Hz · 慢变化99.5%幅度比约 0.9950
10 Hz · 截止处70.7%幅度比约 0.7071
50 Hz · 更快变化19.7%幅度比约 0.1969

如果要求 50 Hz 干扰只剩 1%，这个一阶滤波器明显不够。可能需要更高阶或其他结构，并重新权衡延迟；把截止频率设为 10 Hz 并不能保证全部阻带指标。

查看数值怎么算，以及公式的适用范围
r = 1 − α
|H(f)| = α / √(1 + r² − 2r cos(2πf/fs))

把 f 换成 1、10、50 Hz，即得到上面的比例。要求均匀采样、固定 α，讨论的是稳态正弦响应，初始状态的过渡不包含在这些比例里。

给定 0 < fc < fs/2，上面的设计式得到 0 < α < 2(√2−1) ≈ 0.828427。反过来，α 超过这个上限时，在 0～奈奎斯特频率内没有半功率交点；等于上限时交点在 fs/2。并不是任意 α 都有带内 −3 dB 截止点。

常见近似 α = 1 − exp(−2πfc/fs) 是匹配衰减时间常数的另一种关系。当 fc 远小于 fs 时很接近，但不是上面的精确数字半功率设计式。

“稳态 50 Hz 振幅剩 19.7%”不等于“任意噪声都减少 80.3%”。宽带随机噪声包含很多频率，要结合整个频谱评估。

从 10 Hz 反算平均点数

仍然取 fs = 1000 Hz，但改用 M 点等权滑动平均。M ≥ 2 时，在第一个主瓣内找半功率点，可用：

fc ≈ 0.442946 × fs / M
常用简写：fc ≈ 0.443 fs / M

这是M 较大时的近似，不是所有 FIR 的通用公式。它来自滑动平均主瓣的 sinc 近似；M 很小时应直接解精确响应。

代入这组目标

M ≈ 0.443 × 1000 / 10 = 44.3
试取整数 M = 44
b₀ = b₁ = … = b₄₃ = 1/44

用精确响应复核，得到 fc ≈ 10.0692 Hz。如果要求截止点不能高于 10 Hz，44 就不满足，应按约束选取并验证；M = 45 时约为 9.8453 Hz。

精确响应、首个零点与延迟
|H(f)| = |sin(πMf/fs)|
/ (M |sin(πf/fs)|)

f = 0 时用极限值 1。找从 0 到第一个零点之间 |H(f)| = 1/√2 的根，就是这里的截止频率。M = 1 没有平滑，也没有这个半功率点。

首个零点 f₀ = fs / M
线性相位群延迟 τ = (M−1) / (2fs)

M = 44 时，首个零点约为 22.7273 Hz，而截止点约 10.0692 Hz，二者不同。通带内的群延迟为 21.5 个样本，即 21.5 ms；“44 点窗口”也不等于“44 ms 的群延迟”。

群延迟描述正弦成分的相位斜率；零点处相位无定义。窗口开始到最后一个样本相隔 M−1 个采样间隔；旧样本经过 M 次更新后被移出。

零点不是一堵墙。滑动平均在零点之后还有旁瓣，阻带抑制通常较弱。例如上面的 44 点平均，在 50 Hz 仍保留约 8.54% 的幅度。若要求整个频段的衰减，需逐频段验证，不能只把零点对准一个干扰就结束。

稳定、相位和实现的边界

FIR 的稳定性

固定、有限个、有限大小的系数，作用于有界输入时，理论输出有界：

|y[n]| ≤ max|x[n]| × ∑|bk|

这是 BIBO 稳定。定点溢出、错误索引或运行总和漂移仍可能让实现出问题。

IIR 的稳定性

对因果有理滤波器，约去公共因子后的传递函数极点都在单位圆内，才是 BIBO 稳定。实际实现还要检查内部状态与有限精度。

本页指数平滑的极点为 1−α；在 0 < α ≤ 1 内是稳定的，α = 1 则退化为直接通过。不要把这个特例推广到所有 IIR 系数。

相位：不是“FIR 一定不失真，IIR 一定不好”

实系数 FIR 若具有合适的对称或反对称结构，可以实现精确线性相位；并非每个 FIR 都自动满足。滑动平均的对称系数给出固定群延迟。一般 IIR 的相位与群延迟会随频率变化，是否可接受取决于任务。

MCU 每拍实际做什么？

短 FIR 直接对输入历史乘加；IIR 按差分方程对输入和历史输出乘加。不需要每收一个样本就先做 FFT。频域帮助我们设计和分析，时域公式就能执行滤波。长 FIR 可以为了效率使用 FFT 分块卷积，但不是定义要求。

  • 一般 M 抽头直接 FIR 每拍约 M 次乘法，并保存有限输入历史；滑动平均可用运行总和降低运算量，但仍要记住待移出的旧样本。
  • 本页一阶指数平滑可写成 y ← y + α(x−y)，只需保存一个输出状态，计算轻量。
  • 实现前核对采样周期、初始化、数据类型和系数符号；与离线测试序列逐拍比对。

先独立作答，再看答案

这些题是理解检查，不会自动把“看过”记成“掌握”。先口头解释或写下计算，再展开。

1. 输入 8, 0, 0…，4 点平均为什么是 2, 2, 2, 2, 0…？

在零初始状态和固定分母 4 下，前四个窗口都包含那个 8，各输出 8/4。到 n = 4，窗口只剩 0。如果启动时改用已有样本数作分母，就不是本题的初始化约定。

2. 用“上次总和 + 新值 − 旧值”实现平均，为什么还是 FIR？

在一致初始化、精确算术下，它始终只依赖最近 M 个输入。每个旧样本的影响会在有限时间后完全消失。递推是计算方式，FIR/IIR 是冲激响应分类。

3. 两个滤波器都取 2 个样本，它们一定都是低通吗？

不一定。[0.5, 0.5] 对相近值相加，[0.5, −0.5] 对相近值相减。抽头数一样，权重不同，频率响应就不同。

4. 1000 Hz / 10 Hz 算得 α ≈ 0.060879，是否足够去掉 50 Hz 干扰？

还缺“去掉多少”的指标。这个 EMA 对稳态 50 Hz 的幅度比约为 0.1969。如果要求最多 0.01，它不合格；应重新选结构或指标并验证。

5. 44 点平均的截止约 10 Hz，首个零点和延迟也是 10 吗？

不是。fs = 1000 Hz 时，截止约 10.0692 Hz；首个零点是 1000/44 ≈ 22.7273 Hz；群延迟是 43/2 个样本，即 21.5 ms。它们描述不同的量，单位也不同。

6. 采样率从 1000 Hz 改为 2000 Hz，系数不变，会怎样？

按样本编号看，滤波器不变；按秒看，变化快了一倍。原先约 10 Hz 的截止移到约 20 Hz。若仍要 10 Hz，需要按新采样率重新设计。
