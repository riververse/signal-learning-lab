雷达入门导读

读懂雷达：从回波到判断

先问每一步在解决什么问题，再看算法名字。雷达中的“滤波”只是处理链的一部分；变换、检测、测角和跟踪各有自己的任务。

先把五类算法分开

FIR / IIR · 滤波
保留哪些变化？

按频率或时间尺度抑制不需要的成分。低通更平滑，也可能增加滞后；带通只保留关心的频段。

FFT · 变换
主要频率在哪里？

把采样序列分解到频率坐标。FMCW 可由拍频估距离；呼吸应用分析的是微动随时间的节律。FFT 本身不等于去噪。

CFAR · 检测
这个峰值得保留吗？

参考邻近背景估计自适应阈值，挑出候选点。它做检测判决，不负责把波形变平滑；虚警仍取决于假设和参数。

Beamforming · 测角
回波来自哪个方向？

利用多天线之间的相位关系估计方向。Capon 是其中一种自适应波束形成方法，需要匹配阵列与数据。

KF / EKF · 跟踪
这是上一帧的谁？

数据关联决定测量属于谁；KF / EKF 再结合运动预测更新状态。跟踪处理检测后的测量，不能替代前面的目标检测。

先分清：随机噪声，还是不想要的回波？

随机噪声会抬高底噪；墙面、桌面等真实反射若与当前任务无关，才叫杂波。减去静态背景可以突出运动，也可能消掉你本来要测的静止目标。先确定目标，再决定去掉什么。

对照三个官方案例，沿数据流读实现

脉冲相干雷达 PCR

A121 存在检测 · 看变化

  1. 稀疏 IQ
  2. 帧内偏差 / 帧间快慢低通差
  3. 时间平滑 + 噪声归一化
  4. 分数与阈值

帧内变化对应较快动作；帧间快、慢一阶 IIR 输出之差突出较慢变化，可结合相位增强。重点读“变化量怎样变成存在分数”，不必先上 FFT。

建议起步顺序

  1. 先读呼吸链路

    按距离段 → 相位微动 → 带通 → 频谱逐段读源码。每次只记输入、输出、单位与采样率，先把 IIR 和 FFT 的分工说清楚。

    复习 IIR / FIR

  2. 再做离线小实验

    另起一个 FMCW 教学练习：合成已知拍频与随机噪声，比较不加窗 / 加窗的距离 FFT，再加 CFAR。看峰值、旁瓣与阈值怎样变化；这是建议练习，本站尚未实现雷达仿真。

    复习傅里叶变换

  3. 最后考虑硬件

    读懂数据维度后，再检查官方板卡、固件与接口。GD32 是否能承担所选环节，要评估 RAM、采样率、FFT 点数、精度和帧时限；不能承诺直接跑通完整链路。

    查看嵌入式 DSP 入口
