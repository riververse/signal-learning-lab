这一路更容易抖动
误差方差 R = 64 kPa²

这里的“方差”是什么意思？

想象反复做很多次测量，每次都会有一点误差。把误差平方后再求平均，就得到“平均平方误差”。本例假设误差没有长期偏高或偏低的趋势，此时它等于误差的方差。

方差越大，通常越不确定。16 和 64 不是压力值，也不是每次一定会偏差 16 或 64。它们开平方得到 4 kPa 和 8 kPa，叫“标准差”，可以帮助你理解误差的大致尺度，但不是误差上限。

03 / 现在再看公式

为什么权重要平方？

假如一路误差只保留原来的二分之一，那么它的平方就只剩四分之一。所以计算误差方差时，权重也要平方。

融合方差 = (1 − K)² × 16 + K² × 64

左边一项来自预测误差，右边一项来自测量误差。本例假设两路误差没有长期偏差，而且互不相关，因此可以这样相加。

展开配方，看看 0.2 怎么来的
(1 − K)² × 16 + K² × 64
= 16 − 32K + 16K² + 64K²
= 80K² − 32K + 16
= 80(K² − 0.4K + 0.04) + 12.8
= 80(K − 0.2)² + 12.8

平方不能小于 0。K = 0.2 时，平方项恰好为 0，剩下的 12.8 就是最小方差。它对应 100 × 0.8 + 110 × 0.2 = 102 kPa。

把 16 和 64 换成任意正的 P 和 R，同样配方得到：

融合方差
= (P + R)[K − P/(P + R)]²
　 + PR/(P + R)

因此，令平方项等于 0，就得到你课上见过的 K = P/(P + R)。这里的 P 指“预测后的方差”，已经包含预测阶段加过的 Q，这里不再加一次。

这里的“最好”，是指在这些假设成立时，让反复试验的平均平方误差最小，不保证这一次就最接近真实压力。只有选中最优权重时，我们才把它叫作本例的最优卡尔曼增益。
