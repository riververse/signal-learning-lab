先回答你最关心的问题

网页原来的简化

FIR：全部系数相等，所以只暴露窗口长度 N。
IIR：选择一阶指数平滑，所以只暴露 α。
卡尔曼：只估计压力，所以矩阵退化成了几个数。

更一般的工程设计

FIR：决定多少个系数、每个系数取多少。
IIR：决定滤波类型、截止频率、阶数与各节系数。
卡尔曼：决定估计哪些状态、它们怎样变化、传感器测到什么，再选不确定性。

复杂不是目的。一阶 IIR 本身就在真实传感器中使用；如果它已满足噪声与响应指标，就没有必要为了“高级”而加阶数。

工程顺序通常是：先明确需要保留的变化 → 确定采样率和干扰频段 → 规定允许的误差与延迟 → 设计系数或模型 → 用真实数据验证。

01 / FIR：从平均，变成有目的地加权

真实案例：称重 ADC 的工频抑制

TI ADS1262 的内置 FIR 用于低通与降采样，并能同时抑制 50/60 Hz 工频。TI 官方称重示例采用 20 SPS（每秒 20 个输出）配合 FIR。这里的 20 SPS 是最终输出速率，不能把它当成芯片内部所有滤波环节的采样率。

TI ADS1262 数据手册 · TI 官方称重示例

动手设计：保留缓慢压力，减轻较快干扰

下面是独立的工程教学设计，并非上述 ADC 的内部系数。输入是 100 Hz 等间隔采样的压力；输出还是压力，但不同频率的变化被不同程度地保留。

横轴 Hz，纵轴为幅度保留比例，1 表示幅度不变。

设计边界不是保证的 −3 dB 点。该窗函数法在滤波器足够长时，边界附近常接近幅度 0.5（约 −6 dB）；短滤波器和窄通带可能偏离很多，以实际曲线为准。这里固定 100 Hz，不能拿本图验证 60 Hz 工频抑制。采样前已经混叠进来的干扰，不能靠事后数字滤波恢复。

公式、可调参数，以及真正的一组系数
y[n] = Σ b[m] × x[n−m]，m 从 0 到 M−1

Σ 表示把这些项全加起来。x 是输入，y 是输出，n 是当前采样编号，m 表示往前数多少点，b[m] 就是每个样本的权重。负系数允许出现，不代表算法错误。

本例用理想低通的 sinc 形状乘 Hamming 窗，再把系数和归一化为 1。Hamming 窗是一条塑造系数的曲线，不是“最近若干点取平均”的同义词。

u = m − (M−1)/2
h[m] = sin(2π fc u / Fs) / (πu)
u = 0 时取 h[m] = 2fc/Fs
w[m] = 0.54 − 0.46 cos(2πm/(M−1))
b[m] = h[m]w[m] / Σ h[j]w[j]

Fs 是采样率，本例为 100 Hz；π约为 3.14159；sin、cos 是正弦和余弦，角度用弧度。更换 M 或 fc，会重新计算整组权重。

还可以选择窗函数，或用等波纹等方法，根据通带允许波动、阻带衰减与过渡带宽来求系数。本例没有自动证明满足某个产品的正式指标。
实际功能与代价
对称系数带来线性相位：通带内各频率成分具有一致的群延迟，更有利于保持波形相对形状。但本例 63 点就延迟 310 ms，对快速闭环控制可能完全不合适。增加点数通常能让过渡更陡，同时增加计算、存储与延迟。


02 / IIR：α 只是最简单的一种表达
真实案例：气压传感器 BMP280
Bosch BMP280 内置的一阶 IIR 用来降低关门、风吹等短时气压扰动的影响。官方建议中，楼层变化检测可用滤波系数 4，室内导航可用 16，而掉落检测建议关闭滤波。因为掉落检测需要保留快速响应。
y[n] = (1−1/C)y[n−1] + x[n]/C
所以，首页的 α = 1/C
C = 4 达到阶跃变化的 75% 约需 5 个样本；C = 16 约需 22 个样本。多少秒还取决于输出速率。这个案例说明：简单算法可以很实用，参数名字也可能因厂商而不同。

另一种设计：多阶 Butterworth 低通
假设一阶滤波对带外干扰削弱不够，而可接受更复杂的相位与瞬态响应，可以尝试更高阶 IIR。下面不是 BMP280 的实现，而是适合在 MCU 上实现的另一种设计。
横轴 Hz，纵轴为幅度保留比例。Fs 固定为 100 Hz。更高阶通常使带外衰减更快，但不代表整体效果必然更好。
它有哪些系数？为什么不用一个 α？
每个二阶节都执行下面这一条递推。当前输出既依赖最近三个输入，也依赖前两个输出；将一节的输出作为下一节的输入，就是串联。
y[n] = b₀x[n] + b₁x[n−1] + b₂x[n−2]
　　　− a₁y[n−1] − a₂y[n−2]
b 是输入权重，a 是反馈系数。这里用分母系数的常见符号约定，a₀已经归一化成 1。下面是当前设计各节的系数。
这里的 Q值是二阶节的“品质因数”，用于形成指定的频率响应；它与卡尔曼的过程噪声 Q 不是一回事。Butterworth 中，各节 Q值由总阶数决定，不是每节都随意设为 0.707。
ω = 2πfc/Fs，t = sin(ω)/(2Q值)
未归一化：
b = [(1−cosω)/2, 1−cosω, (1−cosω)/2]
a = [1+t, −2cosω, 1−t]
最后把所有系数除以 a₀
对于本页偶数总阶数 N，第 k 节的 Q值 = 1/[2cos((2k+1)π/(2N))]，k 从 0 到 N/2−1。
实际功能与代价
多阶 IIR 能以较少系数获得较陡的衰减。代价包括非线性相位、可能的阶跃超调，以及反馈带来的数值稳定性要求。高阶实现常拆成二阶节，而不是直接堆成一个高阶多项式。滤波器阶数、采样率、通带、阻带、允许波动都属于设计考虑，最终才落实成系数。


03 / 卡尔曼：“维度”是要估计多少种状态
真实用途：位置、速度与传感器融合
位置传感器只给位置，滤波器仍可以把“位置、速度”同时放进状态向量，利用连续测量和运动模型估计速度。MathWorks 提供了这种恒速跟踪模型的公开实现说明。实际飞控 PX4 使用更大的扩展卡尔曼模型，将惯性测量与 GPS、气压等观测结合来估计飞行状态。
位置观测、位置与速度状态模型 · PX4 实际导航 EKF
飞控不是把下面的二维代码直接复制过去。姿态、传感器偏置、非线性模型、时延与异常观测处理都会增加复杂度。下面用压力做一个更容易读懂的类比，不声称是某款产品的实际算法。
工程教学例：同时估计压力与压力变化率
输入：每秒 20 次的一个压力读数。输出：较稳定的压力，以及每秒上升或下降多少 kPa。单个传感器也能有两个状态；状态数不等于传感器数量。
先固定 σ，只调 R：这是在改变算法对测量的信任。再调 q：这是在改变模型允许“压力变化速度”变动的程度。σ 改变后不会自动替你匹配 R。

从原来的一维，变成了哪些矩阵？
状态 x = [压力 p，压力变化率 v]ᵀ，ᵀ表示转置，把横排写成列。每隔 Δt = 0.05 秒，先假设变化率短时间内不变：p预测 = p + Δt·v，v预测 = v。
F = [[1, Δt], [0, 1]]
H = [1, 0]
x预测 = F x上次
P预测 = F P上次 Fᵀ + Q
K = P预测 Hᵀ / (H P预测 Hᵀ + R)
x更新 = x预测 + K(z − H x预测)
  • F：状态如何从上次推到这次。本例把压力与变化率联系起来。
  • H：传感器直接看到了什么。[1,0] 表示只直接测压力。
  • P：2×2 状态误差协方差；对角项描述两种不确定性，非对角项描述二者误差的关联。
  • R：本例只有一个观测，所以仍是一个数。多个传感器时通常成为矩阵。
  • K：现在有两项，分别修正压力和变化率；第二项不是百分比，也不必在 0 到 1 之间。
过程噪声采用连续白噪声驱动变化率的模型。q 是强度旋钮，Q 是根据 q 与采样间隔计算出来的矩阵，不能混称为同一个标量：
Q = q × [[Δt³/3, Δt²/2], [Δt²/2, Δt]]
本页用 Joseph 形式更新 P，以改善数值稳健性：P更新 = (I−KH)P预测(I−KH)ᵀ + KRKᵀ。I 是单位矩阵。
卡尔曼实际可调的，不只 Q、R
还包括状态定义、F/H 模型、控制输入及其作用矩阵（如果系统有控制量）、初始状态 x₀、初始不确定性 P₀、采样间隔、过程和测量噪声结构。模型矩阵应根据系统推导，而不是把每个元素当成随意试的旋钮。加状态只有在模型与观测足以支持它时才有意义。


移植到 GD32 / Keil 前，先检查这些
  1. Fs 必须对应定时采样频率，不是屏幕刷新率。采样前要考虑模拟抗混叠；传感器或 ADC 内部滤波的延迟也算在总延迟里。
  2. 每路传感器保存独立的滤波状态，不要每处理一块数据就重置。
  3. CMSIS-DSP FIR 接口要求系数按时间反向排列。本页对称 FIR 看不出反转差异，换成非对称 FIR 就必须留意。
  4. 本页 IIR 公式反馈项带减号；CMSIS DF1 使用反馈系数相加的约定。移植时要按接口翻转 a₁、a₂ 的符号，不能直接照抄。
  5. 先检查直流、正弦扫频、阶跃、异常读数、启动过程，再用真实数据测延迟、超调、噪声与 float32 数值表现。
本页是参数与模型设计实验，不是经过 GD32 硬件认证的驱动或量产算法。公式在网页中用双精度计算；实时周期、数值范围和具体工具链仍需板上验证。
