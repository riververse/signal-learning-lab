每个量各管一件事

这一组符号先服务于前面的一维压力模型。从第 12 节起，x 会变为二分量状态，P 会变为矩阵，K 也会分成两个分量；届时再分别说明单位。

xk
第 k 次时刻的真实压力，通常无法直接知道，单位 kPa。
zk
传感器这次给出的测量，单位 kPa。
x̂k−、x̂k+
读入本次测量前的预测、融合本次测量后的估计。上标 − / + 只区分“更新前 / 更新后”，不表示数值正负；小帽子表示估计量。单位均为 kPa。
Pk−、Pk+
相应估计误差的方差，表示模型认为估计还不确定到什么程度，单位 kPa²。
Q
一个采样间隔内，模型没有预知的真实变化所带来的过程噪声方差，单位 kPa²。
R
单次测量误差的方差，单位 kPa²。这里先假设为固定正数。
P₀
初始估计误差方差，描述刚启动时对初值的把握，单位 kPa²。
Kk
本次卡尔曼增益，决定把预测拉向测量多少，没有物理单位。

P、Q、R 的单位是压力单位的平方。比如标准差为 4 kPa，对应方差 16 kPa²。不能把 P = 16 kPa² 写成“误差就是 16 kPa”，也不能把标准差直接代进需要方差的公式。

先说清楚现在采用什么模型

在当前的一维练习里，下一时刻的最佳中心预测就是上一次估计。真实压力仍然可能变化，只是没有额外趋势信息告诉我们该向上还是向下预测。

真实变化：xk = xk−1 + wk
传感器读数：zk = xk + vk

w 是这一间隔里没预测到的变化；v 是这次测量误差。这里假设它们平均为零，方差分别为 Q 和 R，不同时刻的噪声互不相关，并且过程噪声、测量噪声与相关先验估计误差满足推导所需的不相关条件。

这种模型叫随机游走。它的预测中心不动，而预测的不确定性会增加。就像暂时不知道压力会朝哪边变，最合理的中心仍是原值，但不能因此宣称接下来绝不会变。

这些假设决定公式的适用范围。按模型算出的 P 反映的是模型内的不确定性；传感器固定偏差、强相关噪声或错误的变化模型，都可能使实际误差比它大。

方差为什么值得一起保存

只存一个估计值 100 kPa，还不知道它是“非常确定的 100”，还是“只是暂时猜 100”。P 为后面的融合提供这份把握程度。

设估计误差是“估计值 − 真值”。在无偏条件下，P 是这个误差平方的平均值。平方让正负误差都贡献正数，再开平方得到的标准差 σ 与压力同单位：

σ = √P

例如 P = 16 kPa² 对应 σ = 4 kPa。它不是严格保证的最大误差；若还满足高斯分布等条件，才可以进一步谈“多少倍标准差内的概率”。

两个不相关误差，方差怎样合并

如果误差分别乘 a 和 b 再相加，且两者不相关，那么合成方差是 a²P₁ + b²P₂。系数需要平方，因为方差本身计算的是平方误差。这条规则会在第 10 节的增益推导中直接用上。

模型里的 P 变小，表示加入信息后模型更有把握。它不等于这一次的真实误差必然变小，也不保证存在系统偏差时仍然准确。

五步递推 每一步解决一个问题

  1. 预测中心

    x̂k− = x̂k−1+

    当前模型没有趋势项，下一步先沿用上次估计。

  2. 预测不确定性

    Pk− = Pk−1+ + Q

    时间又过去一个采样间隔，未建模变化会增加不确定性。

  3. 决定这次测量参与多少

    Kk = Pk− / (Pk− + R)

    预测越不确定，K 越大；测量越不确定，K 越小。这里 Q ≥ 0、P ≥ 0、R > 0，因此 0 ≤ K < 1。

  4. 更新估计

    x̂k+ = x̂k− + Kk(zk − x̂k−)

    括号里的“测量 − 预测”叫新息，也可以先理解为本次差值。K 决定沿这个差值走多远。等价写法是 (1 − K) × 预测 + K × 测量。

  5. 更新不确定性

    Pk+ = (1 − Kk)Pk−

    融合了新信息后，模型内的估计不确定性减小。更新后的 x̂ 与 P 一起留给下一轮。

这里的 P 更新简式使用了最优 K。一般的加权融合误差方差应写成 (1 − K)²P− + K²R。实现时，后一个非负项相加的形式也是常见的数值稳健写法。

代码顺序也照这五步走。要先算 P−，再用它算 K；不能误用上一轮的 P+。只保留当前 x̂、P 和参数即可递推，不需要保存全部历史测量。

把熟悉的 100 和 110 连成一整轮

这一轮已经预测完成：x̂− = 100 kPa，P− = 16 kPa²。新测量 z = 110 kPa，测量方差 R = 64 kPa²。不要在同一轮又给 16 加一次 Q。

K = 16/(16 + 64) = 0.2
x̂+ = 100 + 0.2 × (110 − 100) = 102 kPa
P+ = (1 − 0.2) × 16 = 12.8 kPa²

测量比预测高 10 kPa，这次只向它走 20%，也就是 2 kPa。因为测量方差较大，结果更靠近预测。

下一轮到来，设 Q = 12 kPa²

x̂下一轮− = 102 kPa；P下一轮− = 12.8 + 12 = 24.8 kPa²

这两个数在练习中已经正确算出。重要的连接是：中心预测保持 102，不确定性却可以从 12.8 增到 24.8。

如果这时测量恰好也是 102，会发生什么？

新息为 0，所以估计仍为 102 kPa。但只要这是一次有效的新测量，它依然提供了信息。

K = 24.8/(24.8 + 64) ≈ 0.2793
P+ = (1 − K) × 24.8 ≈ 17.8739 kPa²

相较本轮更新前的 24.8，不确定性降低了。它仍高于上一轮更新后的 12.8，是因为中间经过了过程噪声 Q 的增加。比较 P 时，要对齐“哪一轮、更新前还是更新后”。

没收到测量时 继续预测而不假装更新

有缺测标志时，仍按真实过去的时间做预测；本轮跳过测量融合，把预测值作为当前结果。不能把上次读数重新喂进去，假装得到了一次独立的新测量。

缺测时：x̂k+ = x̂k−；Pk+ = Pk−

两次缺测的例子

从某次更新后的 x̂ = 105 kPa、P = 12.8 kPa² 开始，每步 Q = 12 kPa²。一次缺测后为 105 和 24.8；第二次后为 105 和 36.8。中心不动，但对它的把握持续下降。

如果改成 Q = 0，且没有任何测量，那么 P 仍是 12.8。这个结论依赖模型假设为“压力没有未知变化”；真实设备若在变，设 Q = 0 可能使模型过度自信。

相同的数值 不一定是重复的数据

两次独立采样都读到 102，可以是两条新信息；将同一条 102 读数复制两遍，则没有获得第二条独立信息。区别在来源、时间和相关性，而不是屏幕上的数字有没有改变。

测量恢复时，先完成当前时间的预测，再用新 z 更新。缺测累积使 P− 变大时，恢复后的 K 往往更大，测量因此能把估计拉回来更多。

Q 是对应某个时间步的方差。采样间隔改变时不能机械沿用同一个每步 Q。若采用连续随机游走噪声强度 q，则可令 Q = qΔt，其中 q 的单位是 kPa²/s；这属于明确的建模选择。

Q R P₀ 怎样影响结果

R 测量这边有多不确定
其他条件不变时，R 变大，K 变小，对本次测量更谨慎。可以用真实压力基本不变时的重复采样来估计随机测量方差，但实际压力波动、漂移和固定偏差会混入，必须分辨。估计了方差也不能自动消除固定偏差。
Q 每过一段时间 模型会漏掉多少变化
Q 越大，P 的预测增长越快，通常使 K 更大、更愿意跟随新读数；Q 太小可能跟不上变化，太大可能让输出更抖。它描述模型无法解释的变化，并非只由传感器静态噪声决定。
P₀ 开机时 对初值有多确定
P₀ 大表示初值不够可信，开始时更愿意听测量；P₀ 小表示较信任初值。常数 Q > 0、R > 0 的这类模型在持续有效测量下，初始影响会逐渐减弱，但不能据此随意填写启动值。

例如 R = 64 kPa² 表示测量标准差为 8 kPa；Q = 12 kPa² 表示这一个时间步内的过程噪声标准差约为 3.46 kPa。它们都是平方单位，但描述的误差来源不同。

防止“自信到不再听测量”。若 P₀ = 0 且 Q = 0，之后 P− 一直为零，K 也一直为零。即使初始估计错误，算法也不会用测量修正。

定性自检：输出过于迟钝，就一定应该把 R 调小吗？

不一定。需要先检查模型是否漏掉真实趋势、Q 是否过小，以及 R 是否有测量依据。随意把真实很吵的传感器设得很可靠，可能让曲线反应快却显著更抖。调参应结合实际变化速度、采样间隔和误差来源。

K 为什么等于 P 除以 P 加 R

先不背最优 K。假设我们打算把预测和测量按 (1 − K)、K 两个权重融合。预测误差记为 ep，测量误差记为 em，则融合误差为：

e = (1 − K)ep + Kem

在误差均值为零且两者不相关的条件下，交叉项的平均为零。于是更新后的误差方差是：

J(K) = (1 − K)²P− + K²R

现在要挑一个 K，让 J 尽可能小。展开再配方：

J(K) = (P− + R)K² − 2P−K + P−
J(K) = (P− + R)[K − P−/(P− + R)]² + P−R/(P− + R)

后面一项与 K 无关。前面是“正数 × 平方”，最小只能到 0，因此取：

K = P−/(P− + R)

这不是靠经验凑出的权重，而是在上述条件下，让这类线性融合的误差方差最小的选择。再把它代回 J，得到：

P+ = P−R/(P− + R) = (1 − K)P−

“最优”始终带着假设。非高斯情况下，这仍可作为相应条件下的最优线性估计；在线性、高斯模型及正确统计假设下，卡尔曼估计还有更强的概率意义。若误差相关或存在偏差，需要调整模型，不能把本页的最优结论无条件推广。

不做求导也能回答：为什么配方后能直接找最小值？

因为平方项不会小于零，且 P− + R > 0。把方括号设为零，就把所有可由 K 改变的额外误差降到最低；剩下那项是这次融合在假设下能达到的方差。

一维卡尔曼怎样接上 EMA

EMA，也常叫指数滑动平均，是前面见过的一阶平滑递推：

yk = (1 − α)yk−1 + αzk

当前随机游走卡尔曼的中心预测沿用旧估计，因此状态更新恰好具有相同形式：

x̂k+ = (1 − Kk)x̂k−1+ + Kkzk

区别在权重怎么来：EMA 通常直接选固定 α；卡尔曼根据 P、Q、R 递推算 K，并且同时追踪不确定性。单凭某一段波形相近，不能把一般卡尔曼滤波都当成固定权重平均。

固定参数下 K 会趋向哪里

在 Q > 0、R > 0 固定、时间步固定且持续有有效测量的当前标量模型中，P 和 K 会趋向稳定值。稳定后，令 α 等于这个 K，状态更新就与相应 EMA 一致。

Q/R = K∞² / (1 − K∞)

下标 ∞ 表示进入稳态的极限值。这个式子说明稳态权重由 Q/R 决定。Q/R 增大，稳态 K 增大；Q/R 减小，稳态 K 减小。

这条关系怎样从原公式得到

稳态时，记更新后方差为 P。最优更新满足 P = KR，又有 P− = P + Q，以及 P = (1 − K)(P + Q)。整理得 KP = (1 − K)Q；再代入 P = KR，得到 K²R = (1 − K)Q。

当 K 稳定在 0.2 时

Q/R = 0.2²/(1 − 0.2) = 0.05

例如 R = 64 kPa²，Q = 3.2 kPa²，才对应这个稳态比例。前面第一次融合算出 K = 0.2，只来自那一刻 P− = 16、R = 64；若之后每步使用 Q = 12，不能据此说 K 将一直等于 0.2。

缺测、可变采样间隔、变化的 Q/R，或增加趋势状态，都可能让这段等价关系失去固定 EMA 的形式。Q = 0 的常量模型也需单独看：反复加入独立测量时，增益会逐渐减小，而非维持一个正的固定 α。

压力与变化率 一起预测和修正

第 12 节已讲解；理解尚待独立作答确认。

如果压力持续上升，只用“下一刻仍等于上一刻”的预测会总落后一点。现在多保存一个量：压力每秒大约在怎样变化，让预测本身也能往前走。

p
压力，单位 kPa。
v
压力变化率，单位 kPa/s。v = 20 表示压力每秒约增加 20 kPa；它不是流体流速，也不是物体运动速度。
Δt
两次时刻之间实际经过的时间，单位 s。
x = [p, v]ᵀ
把压力和变化率装进同一个状态。ᵀ 表示转置，这里就是把横着写的两个分量竖排成一列。x̂ = [p̂, v̂]ᵀ 是相应的估计。

符号在这里重新约定：从本节起，v 专指压力变化率。前面一维模型里的 vk 表示测量噪声；下面改用 nk 表示测量噪声，避免把两者混在一起。

先按当前趋势预测一个短时间步

采用“这一小段时间内变化率近似不变”的模型。上次更新后的估计带 +，本次测量到来前的预测带 −：

p̂k− = p̂k−1+ + v̂k−1+Δt
v̂k− = v̂k−1+

第一式里的 kPa/s × s 得到 kPa，才能和压力相加。第二式并不是宣称真实变化率永远不变，而是说：没有额外变化信息时，先用已有变化率作中心预测，漏掉的变化另由过程噪声描述。

用矩阵只是把这两条计算紧凑地写在一起。下面的 F 有两行两列，H 有一行两列：

F=[1Δt01]；H = [1, 0]
x̂k− = Fx̂k−1+；zk = Hxk + nk = pk + nk

F 的第一行是在算“压力 + 变化率 × 时间”，第二行是在保留变化率。H 则从状态里取出压力，所以预测的传感器读数是 p̂−。H 中的 0 只表示这一次传感器没有直接测量变化率；连续的压力读数结合 F 中的时间联系，仍能提供关于变化率的信息。

从 100 kPa 向前走 0.01 s

上次 p̂ = 100 kPa、v̂ = 20 kPa/s，Δt = 0.01 s：

p̂− = 100 + 20 × 0.01 = 100.2 kPa
v̂− = 20 kPa/s

同样的单位检查也适用于较慢的变化：若 v̂ = 2 kPa/s，经过 0.5 s，压力预测就是 100 + 2 × 0.5 = 101 kPa。

一条测量 一个新息 两个修正

传感器仍然只给出压力 z。先算一次新息 y，再让两个增益分别把它转换成压力修正和变化率修正：

y = z − p̂−
p̂+ = p̂− + Kpy
v̂+ = v̂− + Kvy

两个式子使用的是同一个更新前新息，不是先更新压力，再用 z − p̂+ 去更新变化率。Kp 没有单位；Kv 的单位是 1/s，因为它要把 kPa 的新息换成 kPa/s 的变化率修正。

把 0.3 kPa 的新息用在两个状态上

接上刚才的预测，若 z = 100.5 kPa，本次增益为 Kp = 0.4、Kv = 5 s⁻¹：

y = 100.5 − 100.2 = 0.3 kPa
p̂+ = 100.2 + 0.4 × 0.3 = 100.32 kPa
v̂+ = 20 + 5 × 0.3 = 21.5 kPa/s

测量比预测高，这组增益会同时抬高压力估计与上升趋势估计。再过同样的 0.01 s，下一轮中心预测成为：

p̂下一轮− = 100.32 + 21.5 × 0.01 = 100.535 kPa

这些数是已讲解的示例，不代表已经独立做对。0.4 和 5 也不是凭空指定的永久常数；下一节用预测协方差说明它们可以怎样算出来。

前面标量增益“位于 0 和 1 之间”的结论不能套给 Kv。它有 1/s 的单位，不是两份压力之间的混合比例；数值可以大于 1，也可以因误差联系的方向而为负。

协方差 把两个误差联系起来

第 13 节已讲解；理解尚待独立作答确认。

一个状态时，P 只需回答“压力估计有多不确定”。两个状态时，还要记录“变化率有多不确定”，以及“这两个估计的错误是否常一起偏向同一边”。于是 P 从一个数变成两行两列的协方差矩阵。

先确定是在谈估计误差

ep = p̂ − p真实；ev = v̂ − v真实

两种误差都约定为估计值 − 真值。正数表示估高，负数表示估低。E[·] 表示按照各种可能情况的概率取平均；先在误差均值为零的假设下写：

Ppp = E[ep²]；Pvv = E[ev²]
Ppv = E[epev] = Pvp
P=[PppPpvPvpPvv]
  • Ppp：压力误差方差，单位 kPa²。
  • Pvv：变化率误差方差，单位 (kPa/s)²。
  • Ppv = Pvp：两种误差的协方差，单位 kPa²/s。相等是因为 epev 与 evep 相同。

非对角项为正，表示两种误差倾向于同号：压力估高时变化率也较可能估高，压力估低时变化率也较可能估低；为负则倾向于反号。它描述的是误差之间的联系，不是“压力的数值较大，变化率就一定较大”。

Ppv = 0 只表示这种二阶线性联系为零，一般不能据此断言两个误差完全独立。矩阵不同位置的单位也不同，不能直接用 650 比 4 大来断言哪一个量“更不准”。

如果误差均值不为零，为什么要先减去均值？

协方差衡量的是围绕均值的波动。令 μp = E[ep]、μv = E[ev]，一般定义为：

Ppp = E[(ep − μp)²]
Ppv = E[(ep − μp)(ev − μv)]
Pvv = E[(ev − μv)²]

只有均值为零时，才可简写成上面的误差乘积平均。存在偏差时，均方误差还包括偏差平方；协方差很小也可能一直估偏，不能把“波动小”当成“必然接近真值”。

用四种可能误差 看清 4、50 和 650

假设某次预测完成后有下面四种等概率的误差情况。每一对按 (ep, ev) 排列，第一项单位是 kPa，第二项单位是 kPa/s：

(−2, −30)、(−2, −20)、(2, 20)、(2, 30)

它们是同一时刻的不确定性示意，不是四次连续传感器读数，也不是要求单片机拿真值来算误差。两列的平均值都为 0，所以可以直接计算乘积平均：

Ppp− = (4 + 4 + 4 + 4)/4 = 4 kPa²
Ppv− = (60 + 40 + 40 + 60)/4 = 50 kPa²/s
Pvv− = (900 + 400 + 400 + 900)/4 = 650 (kPa/s)²
P−=[45050650]

这里的 4 和 650 分别描述两种误差的散布；50 把两者联系起来。上标 − 特意保留：接下来的增益要用本次预测协方差，不能误拿上次更新后的 P 来代替。

为什么压力测量能修正没有直接测到的变化率

仍令 H = [1, 0]，测量噪声均值为零、与预测误差不相关，方差为 R > 0。一次压力新息的不确定性记为 S：

S = Ppp− + R
Kp = Ppp−/S；Kv = Pvp−/S

两个增益使用同一个分母，因为它们面对的是同一条压力新息。Kp 的分子是压力方差；Kv 的分子是变化率误差与压力误差的协方差，所以会把已知的误差联系用于修正变化率。

接回第 12 节的两个增益

取刚才的 P−，并设这次测量方差 R = 6 kPa²。它是本例的设定，与前面一维算例的 R = 64 不同。

S = 4 + 6 = 10 kPa²
Kp = 4/10 = 0.4
Kv = 50/10 = 5 s⁻¹

因此，第 12 节使用的 0.4 和 5，可以由这一组预测协方差和测量方差得到。当 y > 0 时，测量提示压力预测可能偏低；由于本例的误差协方差为正，变化率预测也可能偏低，于是它会一同向上修正。这是带着噪声和模型假设的信息融合，不是从一条读数直接知道真相。

只看本次更新：如果 Pvp− = 0，变化率会怎样？

本次 Kv = 0，因此这一条压力新息不会直接修正 v̂。它不意味着以后永远无法估计变化率：后续的状态传播可以重新建立误差联系，而连续压力读数也包含趋势信息。这里仍需区分“本次没有直接修正”和“整个序列不能估计”。

实际单片机保存并递推的是估计 x̂ 与模型给出的不确定性 P。它通常没有真值可随时比较。P 从初始设定开始，结合 F、Q、H、R 预测和更新；正确的模型与噪声设定，才使这份不确定性有参考意义。如何把 P 向前预测，留给下一节展开。

下一步 让不确定性也向前预测

第 14 节预告，尚未计入已讲解内容。

现在已经有了两个并行问题：状态怎么向前走，以及对这个状态的把握如何变化。第 12 节用 F 预测中心；下一步要让压力误差、变化率误差和它们的联系一起传播。

Pk− = FPk−1+Fᵀ + Q

这里 Pk−1+ 是上次更新后的二状态协方差，Fᵀ 是 F 的转置，Q 是这个时间间隔的二状态过程噪声协方差矩阵。它已经不是前面一维模型的单个 Q。下一节再从误差如何传播解释这个公式，以及为什么两边都出现 F。

进入下一节前的检查点

  1. 能区分压力 p 与压力变化率 v 的单位，并把两条预测式对应到 F 的两行。
  2. 能说明为什么两个状态用同一个更新前新息，却用不同单位的增益。
  3. 能说清 P 的对角项和非对角项各记录什么，以及为什么 K 要使用 P−。
回看一维模型时，保留这三个基础检查
  1. 能说明没有测量时，为什么 x̂ 可以不动、P 却继续增加。
  2. 能说明两次相同读数何时算两条新信息，何时只是重复旧信息。
  3. 能解释增益公式中的 P 应取当前预测方差 P−，并说清 Q / R 为什么影响稳态权重。
综合检查：测量忽然变大，K 一定也会变大吗？

在当前线性标量模型里，K 由 P− 和 R 决定，公式没有 z。读数突然变大，会使新息变大，从而可能产生更大的修正；它本身不会直接改变本次 K。根据异常或残差额外调整 R 属于另一个需要明确说明的策略。
