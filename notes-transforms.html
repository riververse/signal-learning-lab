现在走到哪里

当前重点：把“复数旋转”的图像，与“余弦一路、正弦一路”的实际计算接起来。

  • 练习已验证：5 Hz 逆时针旋转与 4 Hz 顺时针旋转相乘，剩下 1 Hz 逆时针旋转；幅值为 4 的余弦可分成两根长度为 2 的反向旋转箭头；C(3) 从 2 变成 −2 代表相位改变。
  • 已经讲到：复数乘法、欧拉公式、频率相乘、积分或求平均、四点系数、相位，以及系数模长与幅值的关系。
  • 仍需确认：余弦和正弦两路比较为什么能表示实部、虚部；不能把“任意周期信号的四个等间隔样本平均为零”当成通用结论。

继续入口：先读两路比较，然后做C(3) = 3 + 4i。这道题在当前学习记录里还没有作答，因此保留为待检验点。

这条路线怎样连起来

  1. 复数是二维坐标。用一个数同时保存横向和纵向信息。
  2. 乘以 i 会旋转。从坐标运算走到箭头转动。
  3. 欧拉公式描述匀速转动。角度随时间增长，频率决定转速。
  4. 乘上反向参考。匹配的旋转停下来，不匹配的继续转。
  5. 求平均提取稳定部分。在合适观察长度和采样条件下，绕圈部分相互抵消。
  6. 实余弦拆成两根箭头。解释正负频率与“一半幅值”。
  7. 四个样本真正算一次。得到 C(3) = 2，再讨论正负号和相位。
  8. 当前这一步。把同一个计算拆成 cos / sin 两路，再从复数恢复幅值与相位。

后续才需要系统展开 DFT 频点、采样、混叠、窗函数与频谱泄漏。拉普拉斯变换和 Z 变换也属于后续连接，不计入本页已经完成的学习进度。

先认清每个符号

x(t) / x[n]
连续时刻 t 的信号值 / 第 n 个采样值。可以是压力、电压，也可以是没有物理单位的练习数值。
t、f、ω
t 是时间，单位 s；f 是频率，单位 Hz，即每秒多少圈；ω = 2πf 是角频率，常写作 rad/s。
i
满足 i² = −1。工程资料也常写 j，意义相同。
A、φ
A ≥ 0 是正弦或余弦的峰值幅度，与 x 同单位；φ 是初相位，公式中默认用弧度。π rad = 180°。
N、Δt、fs
N 是样本数量；Δt 是相邻样本的时间间隔；采样率 fs = 1/Δt，单位 Hz。
C(f)
本页使用的归一化复系数：信号乘参考后再求平均。它与 x 同单位。
C(f) = (1/N) ∑n=0N−1 x[n] e−i2πf nΔt

∑ 的意思是把每个样本对应的一项加起来，再除以 N。这里采样时间从 t = 0 起算；改变时间原点会改变相位读数。

约定很重要：一些书和 FFT 库用不除以 N 的 X[k]，所以 X[k] = N C(fk)，其中 fk = kfs/N。看到系数数值不同，先核对是否归一化，再判断计算对不对。

复数怎样成为旋转箭头

把 a + bi 看成从原点指向 (a, b) 的箭头。实部 a 记录横坐标，虚部 b 记录纵坐标。箭头长度由勾股定理得到：

|a + bi| = √(a² + b²)

例如 3 + 4i 的长度是 5。实部 3、虚部 4 与长度 5 是不同信息，不能只取实部来代表整个箭头有多长。

乘以 i 时，直接展开：

(a + bi)i = ai + bi² = −b + ai

坐标从 (a, b) 变成 (−b, a)，正好是逆时针转 90°，长度保持不变。比如 2 + 3i 变成 −3 + 2i。连续乘两次 i 就转 180°，所以 i² = −1 与几何图像吻合。

“虚部”是这套坐标的名字。传感器输出仍然可以是实数；分析时用两个坐标保存幅值和相位信息，并不要求硬件输出某种“虚数电压”。

欧拉公式把角度写成一个数

eiθ = cos θ + i sin θ

右侧的坐标 (cos θ, sin θ) 在单位圆上，因此 eiθ 可以当作长度为 1、角度为 θ 的箭头。这是一个公式对应两个坐标的简洁写法。

令 θ = 2πft，角度就随时间匀速增加。ei2πft 逆时针每秒转 f 圈，e−i2πft 则顺时针转。同一时刻，两根复数箭头相乘时，长度相乘、角度相加：

ei2πf₁t e−i2πf₂t = ei2π(f₁−f₂)t

已经做对的例子

5 Hz 逆时针 × 4 Hz 顺时针 = 1 Hz 逆时针。若第二根改成 5 Hz 顺时针，相对旋转速度变为 0，乘积停住。

这里的“相乘”发生在每一个相同的时刻，不能把先后的样本随意拼接。后面计算傅里叶系数，就是对每一个采样值做这种配对运算。

为什么反向旋转后再求平均

想找 3 Hz 成分，就用 3 Hz 顺时针的参考去乘信号。信号里正向 3 Hz 的那根箭头会停下来：它的结果一直朝同一方向，累加时不会互相抵消。其他频率还在转，累加时往往会互相抵消一部分。

匹配：ei2π3t e−i2π3t = 1
不匹配：ei2π5t e−i2π3t = ei2π2t

把平均想成“这些箭头首尾相加后，还剩多少，再除以个数”。停止的箭头能留下稳定结果；均匀绕完整圈的箭头可以正负抵消。

有条件才能恰好抵消。有限长记录里，如果剩余旋转没有覆盖整数圈，平均可能不为零；采样过稀也会混叠。在 DFT 的整频点和完整 N 点记录上，不同基准旋转具有精确的正交关系。先保留这个条件，不必现在背泄漏公式。

一个真实余弦为什么有两根旋转箭头

正向与反向单位箭头相加，纵向分量抵消，横向分量叠加：

cos θ = (eiθ + e−iθ)/2
A cos(2πf₀t + φ) = (A/2)eiφei2πf₀t + (A/2)e−iφe−i2πf₀t

因此，幅值为 4 的实余弦，可以用两根长度为 2、方向相反的旋转箭头表示。它们组合后，信号在实数轴上来回变化。

用正频率 f₀ 的反向参考去比较，会留下正向那根的系数：

C(f₀) = (A/2)eiφ

这解释了为什么前面算到 C(3) = 2 时，原余弦的峰值幅度是 4。另一半在对应的负频率里。对于实数信号，C(−f) 是 C(f) 的共轭，即虚部反号。

本节等式指理想、匹配的余弦，并满足完整周期或相应 DFT 整频点条件。后面会单独列出直流、奈奎斯特频点和加窗时的区别。

C(3) = (4 + 0 + 4 + 0)/4 = 2

原始四点直接平均是 0；乘过参考后的平均是 2。后一种运算保留了“这个频率与信号怎样配合”的信息。

四点只用于把计算动作看清。它没有证明任意周期波形只取四点就足够，也没有证明周期波形的均值一定为零。带偏置的 2 + cos θ，均值就包含 2；更高频成分还可能在这四点上混叠。

当前重点：为什么会有实部和虚部

先暂时不想旋转。对同一组实数样本，做两遍“逐点相乘，再求平均”：

  1. 第一遍与 cos θ 比较，得到 U。
  2. 第二遍与 sin θ 比较，得到 V。
U = (1/N)∑ x[n] cos θn，V = (1/N)∑ x[n] sin θn

U、V 都是普通实数。符号相同的样本对相乘为正，符号相反的相乘为负；累加结果反映信号与参考在这段记录上的配合程度。只看一条参考会漏掉相差四分之一周期的分量，所以需要两条。

现在把欧拉公式代回原来的定义：

e−iθ = cos θ − i sin θ
C = (1/N)∑ x[n](cos θn − i sin θn) = U − iV

于是 Re(C) = U，Im(C) = −V。这一步只是把两路计算结果装进一个复数。虚部前的负号来自本页选择的负指数参考。若把第二路参考直接定义为 −sin θ，则第二路结果就是虚部本身。

余弦一路和正弦一路各测到什么

在完整周期、匹配频率条件下，cos² 的平均为 1/2，sin² 的平均为 1/2，cos·sin 的平均为 0。

  • x = 4 cos θ：U = 2，V = 0，所以 C = 2。
  • x = 4 sin θ：U = 0，V = 2，所以 C = −2i。
  • x = 6 cos θ − 8 sin θ：U = 3，V = −4，所以 C = 3 + 4i。

纯正弦仍然有很强的该频率成分，只是余弦那一路的结果为零。必须把两路结果一起看。

和相位怎样接起来

A cos(θ + φ) = A cos φ cos θ − A sin φ sin θ

与上一段的两路结果对照，得到 U = (A/2)cos φ，V = −(A/2)sin φ，所以 C = (A/2)(cos φ + i sin φ)。同一件事既可以用“长度与方向”描述，也可以用“横向与纵向两个分量”描述。

小检查：为什么 4 sin θ 的 C 是 −2i，而不是 0？

余弦比较 U 为零，但正弦比较 V = 2；C = U − iV，所以 C = −2i。该频率的幅值没有消失，它的信息落在另一条比较路径上。

从 C(3) = 3 + 4i 回到余弦

保留练习：如果这是一个理想、匹配频率的实余弦，在本页归一化约定下，它的峰值幅度是多少？先自己想一下：第一步该取实部，还是先求复数长度？

展开推导和答案
|C(3)| = √(3² + 4²) = 5
A = 2|C(3)| = 10

系数长度是正向旋转分量的幅值 5。原实余弦还有与它配对的负频率分量，因此余弦的峰值幅度是 10。

相位由箭头方向决定：φ = atan2(4, 3) ≈ 0.9273 rad ≈ 53.13°。因此可写成 x(t) = 10 cos(2π·3t + 53.13°)，也可以写成 6 cos(2π·3t) − 8 sin(2π·3t)。公式计算时要保持角度单位一致。

再区分三个容易混用的量

  • 峰值幅度 A：单个余弦从中心线到最高点的距离。本例为 10。
  • 峰峰值：最大值减最小值，单个余弦为 2A。本例为 20。
  • 复系数模长 |C|：在这里为 A/2，本例为 5。

同样地，C 从 2 变成 −2 时，模长仍为 2，余弦峰值幅度仍为 4；箭头方向转了 π，相位改变 180°。写成“负幅值”也能表达波形，但规范表示通常让 A ≥ 0，把正负变化放进相位。

回看时最值得防住的误解

“实部就是幅值。”
实部只是一条坐标。通常先用 √(实部² + 虚部²) 求系数模长，再按定义和信号类型换算幅值。
“频率不匹配，结果就一定是零。”
精确为零需要正交条件。有限观察、非整周期、频点不对齐或采样混叠时，都要重新判断。
“周期信号取四个点就一定抵消。”
周期不等于零均值，四点也可能漏掉波形细节。前面的抵消由特定正弦和采样位置保证。
“任何频谱数值乘 2 就是幅值。”
本页的 A = 2|C| 用于实余弦、归一化系数、正负频率分量可区分、整周期或整频点且未加窗的情形。直流 f = 0 和偶数 N 时的奈奎斯特频点 fs/2 不按成对分量翻倍；不归一化 FFT、加窗和频谱泄漏需要相应校正。复数单向旋转信号也不套这个 ×2。
“虚部非零说明测量不真实。”
它是在表达信号相对参考的相位。输入为实数，傅里叶系数仍可为复数。

下一步只检验这三个连接

  1. 能解释：为何一个正弦信号与余弦比较可以得到零，却仍然包含该频率。
  2. 能计算：给定 U = 3、V = −4，写出 C，并求理想实余弦的峰值幅度。
  3. 能说明条件：用自己的话说出为什么“求平均能抵消”需要合适的观察长度和采样条件。

这三点清楚后，再接 DFT 的第 k 个频点对应多少 Hz，并用更多样本观察同一个信号。这样每增加一个工具，都有前面的直觉可以接住。

一题综合自检：若 C = −3 + 4i，会改变什么？

模长仍为 5，符合本页条件时余弦峰值幅度仍为 10。实部从 3 变成 −3，方向进入第二象限，φ = atan2(4, −3) ≈ 126.87°。改变的是相位，不是模长。不要仅用 arctan(虚部/实部) 而忽略象限。

公式核对：Julius O. Smith，DFT 定义与负指数约定；归一化系数与投影的关系。本页例子与说明按学习路线重新组织。

后续路线 拉普拉斯与 Z 变换

路线预告，尚未计入本页已学进度。

当前先把傅里叶的“参考比较 → 复系数 → 幅值与相位”走通。之后可以把同一套思路接到系统分析：输入怎样经过系统，输出为什么会有延迟、衰减或振荡。

  • 拉普拉斯变换：从连续时间的充放电、衰减和阶跃响应切入，再学习 s、时间常数与传递函数。这里会把纯旋转参考扩展到还带指数衰减或增长的参考。
  • Z 变换：从每隔一段时间更新一次的数字递推切入，把“上一拍怎样影响这一拍”写进 z 的表达式，再接到数字滤波器。

两者都先从具体变化过程和符号含义开始，不在本页提前堆积推导。已有的三大变换实验页可以作为可选预览；页面里展示过的内容不自动算作已经理解。
