换个角度就更好懂。

傅里叶帮你看“有哪些频率”；拉普拉斯帮你研究连续系统怎么响应；Z 变换帮你分析按采样一步步运行的数字系统。它们是分析工具，真正运行在单片机上的通常仍是采样、加减乘除和状态更新。

第一课 / 从你问过的 C(3) = 2 接上

“3 Hz 的系数是 2”，到底在说什么？

先看一条每秒来回变化 3 次的信号。下面的“振幅”是它偏离中间位置的最大距离；中间位置先取 0，不加压力的直流基线。

+3 Hz 的复数系数
−3 Hz 的复数系数

这里选 1 秒为展开区间，用 1 Hz 为频率编号的基准，因此第 3 项对应 3 Hz。若改用这条波形最短的周期 1/3 秒作为基准，3 Hz 就是第 1 项。不能脱离编号约定看 C(3)。

为什么振幅 4，会分成两个 2？

在复数的描述里，一条实数余弦可以拆成两个方向相反、速度相同的旋转。两个旋转各有一半的长度：上下方向的分量互相抵消，左右方向的分量相加，就得到余弦。

4 cos(2π·3t) = 2ej2π·3t + 2e−j2π·3t

正频率、负频率是这两个旋转方向的数学表示，不是两只不同的实体传感器。这里的 j 满足 j² = −1；t 是时间（秒）；2π·3 是每秒旋转的弧度数。

动手试：保持 A = 4，把相位拖到 180°。两个系数都变成 −2，但波形振幅仍是 4。改变的是相位：整条波形翻了个方向。

第二步 / 找出藏在信号里的频率

傅里叶在回答什么问题？

压力读数上叠着一层抖动，你想知道它是缓慢漂移、固定频率的电气干扰，还是多种变化混在一起。傅里叶分析把“随时间变化的曲线”换成“各频率的贡献”，帮助你找到线索。

展开：从乘上反向旋转到求平均

对本例的 1 秒周期展开，频率 f 取整数 Hz：

C(f) = (1/T) ∫₀ᵀ x(t)e−j2πft dt，T = 1 s
  • x(t)：时刻 t 的信号；C(f)：在频率 f 上求出的复数系数。
  • e−j2πft：用频率 f 反向旋转。与它匹配的分量会停住，其他完整转圈的分量平均后抵消。
  • ∫ … dt：把连续时间上每一点的贡献累加；除以 T 是求平均。

先不用自己算积分。它在做的事，就是你之前学过的“旋转之后求平均”。匹配的系数不为零，说明这段信号在这个旋转方向和频率上有贡献。

展开：一般傅里叶变换与单片机里的 DFT

对适合变换的一般连续信号，常用定义为：

X(f) = ∫₋∞⁺∞ x(t)e−j2πft dt

这是傅里叶变换，X(f) 是频率描述。它与上面的周期傅里叶级数系数 C(f) 不是同一套归一化；不要把这里的 X(f) 数值直接当成 C(f)。无限持续的纯余弦在一般变换下用冲激谱线表示，不是普通有限数值“2”。

单片机只能拿到有限个样本，通常计算离散傅里叶变换（DFT）：

X[k] = Σₙ₌₀ᴺ⁻¹ x[n]e−j2πkn/N
  • x[n]：第 n 个样本；N：本次使用的总样本数。
  • Σ：把所有列出的项相加；k：频率格子的编号。
  • 采样率 fₛ 是每秒采多少点；第 k 个格子对应 kfₛ/N。后半部分格子通常解释为负频率。
  • FFT 是快速计算 DFT 的算法，不是第四种变换。

对于恰好落在频率格子上、未加窗的实数余弦，通常用 2|X[k]|/N 得到单边振幅；直流和奈奎斯特频点不能乘 2。加窗后还要处理窗的幅值校正。

在你的工作里怎么用

采集一段 ADC 数据 → 去掉平均值以突出波动 → 做 FFT → 看主要频率 → 再判断干扰来源或设计滤波。傅里叶分析本身不等于已经把噪声滤掉。

频谱峰不能独自证明干扰来源。采样前要考虑抗混叠；采样率必须足够高。记录长度影响频率分辨能力，非整周期截取还会使能量散到邻近频率，这叫频谱泄漏。

第二课 / 从一个 RC 电路开始

输入突然变化，输出为什么慢慢跟上？

想象输入电压从 0 V 突然跳到 1 V，输出经过一个简单 RC 低通电路。电容需要充电，输出不会立即跳到 1 V。

τ（读“陶”）在这个电路中等于电阻 R 乘电容 C。它越大，响应越慢。这里 R 是电阻，不是卡尔曼滤波中的测量方差；相同字母在不同模型中可能有不同含义。

展开：先看时间里的公式
τ × dy(t)/dt + y(t) = u(t)
  • u(t)：输入电压；y(t)：输出电压；t：时间。
  • dy/dt：输出随时间变化的速度，也就是曲线斜率。
  • τ：时间常数，单位秒。此模型对应理想一阶 RC 低通电路。

对初始输出为 0、t = 0 起输入保持 1 V 的情况：

y(t) = 1 − e−t/τ，t ≥ 0

e 约等于 2.718。这个指数函数描述“刚开始变得快，越接近目标越慢”。单位阶跃输入的幅值为 1 V，所以输出也按 V 理解。

第二步 / 拉普拉斯帮我们做什么

把“变化速度的关系”变成代数关系

直接解包含变化速度的方程，常常比较费劲。拉普拉斯变换把连续时间里的关系搬到一个新的变量 s 上，便于求响应、分析系统是否稳定，以及把多个环节连接起来。

展开：变换公式和 s 的含义
X(s) = ∫₀∞ x(t)e−st dt
s = σ + jω
  • 这是单边拉普拉斯变换，通常用于从 t = 0 开始的因果系统。
  • x(t)：待分析的连续时间信号；X(s)：变换后的表达。
  • σ（西格玛）：指数加权部分；ω（欧米伽）：角频率，单位 rad/s，等于 2πf。
  • j² = −1。e−st = e−σte−jωt，可以理解为“指数加权 + 反向旋转”。

σ 不是这个系统必须具有的衰减速度，而是变换变量的一部分。积分不是对所有 s 都收敛；收敛域是变换定义的重要条件。只有相应收敛条件满足，才能在 s = jω 上联系到傅里叶变换。

展开：RC 电路怎么得到 H(s)

在初始输出为 0 的条件下，dy/dt 的拉普拉斯变换是 sY(s)。因此：

τsY(s) + Y(s) = U(s)
(τs + 1)Y(s) = U(s)
H(s) = Y(s)/U(s) = 1/(τs + 1)

U(s)、Y(s) 分别是输入、输出的变换。H(s) 叫“传递函数”，描述输入经过系统后如何变成输出。这里采用零初始条件；有初始储能时，还需把初始条件对应的响应算进去。对本例单位阶跃，U(s) = 1/s，所以 Y(s) = H(s)/s；H(s) 本身的逆变换是冲激响应，不是阶跃响应。

分母 τs + 1 等于零时，s = −1/τ，这个位置叫“极点”。本例 τ 为正，极点在负实轴，所以对应的自然响应随时间衰减。一般有理因果连续时间系统的稳定性，要检查全部极点及适用条件。

在你的工作里怎么用

分析 ADC 前端 RC 低通、传感器响应时间、运放或控制环路中的连续环节。先由电路或物理模型写出关系，再借助传递函数判断响应速度和频率特性，之后才选择硬件参数或离散实现。

拉普拉斯变换不会自动辨认未知电路，也不是直接塞进 ADC 中断运行的“滤波算法”。需要先有模型，并检查它是否近似实际硬件。

第三课 / 回到每次采样的代码

上一拍、这一拍，怎么写进公式？

单片机每隔一段时间处理一次数据。这次输出常常依赖上次输出，这就是数字滤波器的递推关系。Z 变换用 z⁻¹ 简洁地表示“延迟一个采样”。

y[n] = αx[n] + (1 − α)y[n−1]

x[n] 是当前输入，y[n] 是当前输出，y[n−1] 是上一次输出。n 是采样编号。这里用 x 表示输入，与前面压力实验中原始读数用 z 表示的写法只是命名不同；Z 变换里的 z 是复变量，不是某次传感器读数。

实验中，输入从第 0 次采样起变成 1，起始的上一拍输出 y[−1] = 0。所以第一点是 α。它刻意采用零初始状态，与原滤波实验室“用第一个读数初始化”的方式不同。

第二步 / 从代码到传递函数

把延迟写成 z⁻¹

展开：Z 变换定义与符号
X(z) = Σₙ₌₋∞∞ x[n]z−n
  • x[n]：离散序列，第 n 个样本；Σ 表示逐项求和。
  • z：复数变量，可写为 z = rejΩ，r 是距离原点的大小，Ω 是每个采样间隔的相位变化。
  • 这里给出双边定义。因果且负时间为零的序列，只需从 n = 0 加起。
  • 在相应收敛域内，延迟一个采样的序列，变换后多乘一个 z⁻¹。

在单位圆 z = ejΩ 上，并且收敛条件满足时，可得到离散时间信号的频率描述。实际频率 f 与 Ω 的关系是 Ω = 2πf/fₛ。这不是把连续时间的 s 随便改名为 z。

展开：一阶 IIR 的公式怎么来

对上面的递推式取 Z 变换，采用零初始状态：

Y(z) = αX(z) + (1 − α)z⁻¹Y(z)
[1 − (1 − α)z⁻¹]Y(z) = αX(z)
H(z) = Y(z)/X(z)
　 = α/[1 − (1 − α)z⁻¹]

H(z) 是数字系统的传递函数。分母对应的极点在 z = 1 − α。对这个因果一阶系统，|1 − α| < 1 时稳定；本页取 0 < α ≤ 1，输出会平稳地向目标靠近。严格说 α = 1 时系统就是直通，约去形式中的多余项后没有动态极点。

同样方法可以描述 N 点滑动平均：

H(z) = (1/N)(1 + z⁻¹ + … + z−(N−1))

括号里的每一项对应一个延迟后的输入。这正是 FIR 代码里保存最近 N 个样本再平均的结构。

在你的工作里怎么用

分析 IIR/FIR 的递推关系、频率响应和稳定性；把设计好的数字滤波器落实成 C 代码。Z 变换帮助你判断这段递推会做什么，不要求单片机每次都计算一次 Z 变换。

代码里的核心更新：
y = y + α × (x − y)

采样率改变后，同一 α 对应的“按秒计算的反应速度”会变化。定点实现还要检查溢出、舍入误差和系数量化。稳定的数学公式不等于任意数值实现都可靠。

三者怎么接起来？

发现传感器读数有抖动 → 用傅里叶分析了解频率成分 → 用拉普拉斯分析模拟前端或连续系统 → 用 Z 变换分析数字滤波实现 → 回到实际数据验证效果。

这是一个可能的工程流程，不是每个项目都必须用全三种。只想让慢变化读数更稳，简单滤波和实测往往就能先解决问题。
