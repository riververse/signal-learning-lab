1. IIR：每次向新读数靠近一点

具体功能：保留上一次结果，再吸收一部分新测量，减轻读数快速来回跳动。IIR 表示“无限冲激响应”：旧读数的影响不断衰减，但理论上不会在固定步数后完全消失。它属于低通滤波：让缓慢变化较容易保留，让快速变化受到削弱。快速变化既可能是噪声，也可能是真实事件。

公式与符号

y[k] = y[k−1] + α × (z[k] − y[k−1])
  • k：第几次采样；k−1 就是上一次。方括号只是编号，不是乘法。
  • z[k]：这次传感器测量到的压力。
  • y[k−1]：上一次滤波后的压力；y[k] 是本次新结果。
  • α（读“阿尔法”）：新测量占的权重，取大于 0、且不超过 1 的数，没有单位。

代入一次：上次结果为 100，新读数为 110，α = 0.2，那么新结果 = 100 + 0.2 × (110 − 100) = 102 kPa。下一次从这个 102 继续算。

适用场景

缓慢变化的温度、液位、压力显示；希望用很少的存储和运算减轻 ADC 读数抖动。实现时主要保存上一次输出。

实际效果与代价

  • α 小：通常更平滑，但真实压力突变后，跟得更慢。
  • α 大：通常跟得更快，但更多测量噪声也会进入结果；α = 1 时直接输出测量。
  • 不能单靠它判断某个尖峰是故障还是真实冲击。若要捕捉快速压力冲击，过度平滑可能掩盖峰值。
  • 第一次用首个测量初始化，避免从 0 开始产生不必要的启动偏差。

2. FIR 滑动平均：最近 N 次测量等权投票

具体功能：保存最近的一段测量，每来一个新值，就移走最旧的值，再算平均。适合减轻随机抖动。FIR 表示“有限冲激响应”：对这里的滑动平均来说，一个读数离开窗口后，就不再影响后续输出。

公式与符号

y[k] = (z[k] + z[k−1] + … + z[k−N+1]) / N
  • z[k]：本次测量；z[k−1]：上次测量，后面以此类推。
  • N：窗口长度，也就是平均多少个读数，必须是正整数。
  • y[k]：本次平均后的压力。“…”表示中间的样本也要加上。
  • 刚启动、还不足 N 个样本时，按已有样本数量求平均。本页不会补零凑数。

代入一次：N = 4，最近四次读数是 98、102、100、104，那么输出 = (98 + 102 + 100 + 104) / 4 = 101 kPa。

适用场景

稳态压力、称重等允许短时间平均的测量；希望清楚知道“最近多久的数据参与了结果”。本页每秒采样 100 次，N = 20 代表一个样本会在约 0.2 秒后被新样本完全替换。

实际效果与代价

  • N 大：通常抖动减小，但旧读数会拖住真实变化。
  • 假设原来全是 100 kPa，随后一直测到 120，N = 4 时输出依次为 105、110、115、120 kPa。
  • N = 1 时没有平均作用。这个实现需要保存 N 个样本，增加 N 会占用更多存储。
  • 尖峰会被摊到多个输出中，不是被识别并删除。周期干扰能否被抑制还取决于窗口和采样率，不能保证都能去掉。

巴特沃斯与切比雪夫

想保留的频率有多平，想去掉的频率降得多快？

原理学习笔记

先认识两种“怎样放行频率”的性格

低通滤波器让低频较容易通过，让高频受到削弱。巴特沃斯（Butterworth）希望通带尽量平；切比雪夫 I 型（Chebyshev I）允许通带有规律地起伏，换取不同的过渡带表现。它们都不是在某个频率上突然关门。

本页是讲解后的补充导读与互动演示。已讲内容整理在“学习笔记”；阅读与调图不会被记成已掌握。

巴特沃斯：通带平坦

通带“最大平坦”，幅频响应没有等波纹。平坦不代表所有低频都完全不衰减：接近截止频率时，增益仍会下降。

切比雪夫 I：通带等波纹

在允许范围内让通带增益起伏。波纹说的是不同频率受到的增益不同，不是随机噪声；不能只看一条更陡的下降线就判断更好。

切比雪夫 II：阻带等波纹

II 型也叫逆切比雪夫，通带没有等波纹，波纹在阻带。它与 I 型的参数含义不同；下面互动图专门比较巴特沃斯与 I 型。

同为 100 Hz，含义并不相同

巴特沃斯的 Wn 是幅度降到 1/√2（约 −3.01 dB）的截止点；切比雪夫 I 的 Wn 是 −rp dB 的通带边缘。本图对齐的是同阶与参考频率，不是同一套通带、阻带指标下的胜负比较。实际选型要先统一通带边缘、阻带边缘、允许损失和所需衰减，再分别求阶数。

几个参数，分别管什么？

阶数 N
本页低通传递函数分母的阶数。提高阶数通常能让过渡更陡，也增加运算、数值敏感性与动态响应的检查负担；它不是滑动平均的窗口长度。
参考频率 Wn
要结合家族解读。这里显式给了 fₛ，所以 Wn 的单位是 Hz；若库使用归一化频率，就必须再确认它是相对奈奎斯特频率还是采样率。
纹波 rp
切比雪夫 I 的通带最大损失，单位 dB。rp = 1 表示通带增益在 0 到 −1 dB 之间起伏，对应幅度约 1 到 0.891；不是“允许 1% 噪声”。
II 型的 rs
阻带最小衰减，单位 dB。比如 rs = 40 表示阻带增益至多为 −40 dB；II 型的 Wn 对应首次达到 −rs 的边缘，不要直接套 I 型的 rp。

它们和 IIR / FIR 是什么关系？

FIR / IIR 按冲激响应是否有限分类；巴特沃斯 / 切比雪夫描述设计家族。这些家族既可设计模拟滤波器，也常从模拟原型变换成数字 IIR。模拟原型里的 s 域，经过双线性变换可以连接到数字滤波器的 z 域；采样率与频率预畸变必须一起处理。

这里比较的就是数字 IIR 低通，不是两种新的“平均窗口”。工程实现通常用二阶节（SOS）串联，再检查量化、状态初始化、稳定性和是否溢出。幅频图只说明频率分量被放大或衰减多少，还要另看相位、延迟、阶跃超调和振铃。

令 x = Ω/Ω₀ 表示模拟低通原型的归一化角频率，ε² = 10rp/10 − 1。幅度的平方为：

巴特沃斯：|H|² = 1 / (1 + x2N)
切比雪夫 I：|H|² = 1 / [1 + ε² TN(x)²]

TN 是切比雪夫多项式。可以从 T₀(x) = 1、T₁(x) = x 开始，按 Tn(x) = 2xTn−1(x) − Tn−2(x) 逐阶算，不用先记住高阶展开式。

本页是数字低通，所以不能直接用 x = f/100。双线性变换并对 100 Hz 预畸变后，使用：

x = tan(πf / fₛ) / tan(π · 100 / fₛ)，fₛ = 1000 Hz
GdB(f) = 10 log₁₀(|H|²) = 20 log₁₀|H|

这解释了图中 100 Hz 的两个不同读数，也解释了为什么数字频率轴不能直接照搬模拟频率轴。公式计算的是稳态幅度响应，没有自动给出时域启动过程。

怎样把选型接回传感器数据？

讲解中的示例先写下“0–50 Hz 内最多损失 1 dB，100 Hz 起至少衰减 40 dB，采样率 1000 Hz”，再为两个家族分别求阶数和 Wn。这时不强求阶数相同，才是在同一指标下比较实现成本。还要检查信号突变能否及时跟上，以及模拟前端是否已经做好抗混叠。

如果幅值测量更重要，先认真看通带平坦性；如果过渡带很紧且允许纹波，可以把切比雪夫纳入比较。选择依据仍是你的完整指标，不能仅凭“曲线更陡”下结论。

先分清：结构、频率类型、设计家族

低通 / 高通 / 带通说明希望哪些频率通过；FIR / IIR 说明冲激响应是否有限；巴特沃斯 / 切比雪夫说明怎样在频率响应上取舍。它们不是互相排斥的同一级分类。常见数字巴特沃斯或切比雪夫实现是 IIR，也有对应的模拟滤波器原型。

巴特沃斯

通带最大平坦，没有等波纹。靠近截止处仍会衰减；平坦不等于整段增益严格为 1。截止处幅度为 1/√2 ≈ 0.707，约 −3.01 dB。

切比雪夫 I

用允许的通带等波纹换取频率选择性。rp = 1 dB 时，幅度在约 0.891 到 1 之间变化。这里的“波纹”是增益随频率起伏，不是时域信号随机抖动。

切比雪夫 II

通带单调，等波纹在阻带。rs 给出阻带最小衰减；例如 40 dB 对应阻带幅度不超过 0.01。它的临界频率定义不能与 I 型混用。

“更陡”不等于“响应更快”

过渡带陡峭描述频率选择性，不直接说明时间延迟小、阶跃跟得快或没有振铃。选好幅频指标后，还要看相位、群延迟、超调和启动过程。滤得更干净也可能使需要保留的动态失真。

讲解算例：同一组指标下比较阶数

这次先把任务写完整，再让三个家族各自设计。以下是讲解中的示例指标，不是已经确认的实际传感器需求：

  • 采样率 fₛ = 1000 Hz，奈奎斯特频率为 500 Hz
  • 0–50 Hz 为通带，最大损失不超过 1 dB
  • 100 Hz 起为阻带，至少衰减 40 dB
  • 50–100 Hz 留作过渡带，不要求像理想开关一样立即归零

按同一组数字低通指标计算最低阶数，得到：

  • 巴特沃斯：8 阶。Wn ≈ 54.324 Hz，这里的 Wn 是约 −3.01 dB 点；50 Hz 处恰为约 −1 dB。
  • 切比雪夫 I：5 阶。rp = 1 dB，Wn = 50 Hz；Wn 是通带的 −rp dB 边缘。
  • 切比雪夫 II：5 阶。rs = 40 dB，Wn ≈ 88.533 Hz；Wn 是首次达到 −rs dB 的位置，不是巴特沃斯的 −3 dB 点。

从设计结果走向代码：用二阶节串起来

高阶滤波器通常拆成若干二阶节（SOS / biquad）串联；奇数阶设计还会包含一个一阶节。每节只保存有限个状态，整个 IIR 的冲激响应仍可无限衰减延续。

把每节分母首项 a₀ 归一化为 1 后，一种常见系数约定是：

H(z) = (b₀ + b₁z⁻¹ + b₂z⁻²) / (1 + a₁z⁻¹ + a₂z⁻²)
y[n] = b₀x[n] + b₁x[n−1] + b₂x[n−2]
　　　 − a₁y[n−1] − a₂y[n−2]

b₀、b₁、b₂ 是输入项系数，a₁、a₂ 是反馈项系数。若工具输出 a₀ ≠ 1，应先将这一节的所有分子、分母系数都除以 a₀；移植代码时再核对库对反馈符号和系数顺序的约定。

高阶设计不等于重复串联同一个二阶低通。不同极点对通常需要不同 Q 值及相应系数；随手把若干相同二阶节串起来，一般得不到目标阶数的巴特沃斯或切比雪夫响应。SOS 也不免除定点量化、节间增益、溢出和状态初始化的检查。

如果通带内幅值保真重要，要仔细看平坦性与允许损失；如果过渡带狭窄又容许通带起伏，可比较切比雪夫 I；如果通带不想有等波纹，也可把切比雪夫 II 纳入比较。最后一起核对所需阶数、运算量、数值稳定性与时域表现，没有一个家族在所有问题上都更好。

3. 一维卡尔曼：结合预测与测量的不确定性

具体功能：先预测压力，再用新测量修正。它除了估计压力，还维护“当前估计有多不确定”。权重由这些不确定性计算出来。本例预测规则很简单：下一次压力先沿用上次估计。

先把符号认清

  • x：压力估计；z：传感器新测量，单位都是 kPa。
  • P：压力估计误差的方差。方差描述误差波动的大小，不是压力值，也不是每次实际误差。
  • Q：一个采样间隔内，真实压力变化带来的不确定性。
  • R：测量误差方差。若测量噪声标准差为 σ，通常以 R = σ² 作为起点。
  • P、Q、R 的单位是 kPa²；K 是给新测量的权重，没有单位。
  • 下面的“预测”是尚未融合本次测量的结果，“更新”是融合之后的结果。

每收到一个读数，做这五步

① x预测 = x上次
② P预测 = P上次 + Q
③ K = P预测 / (P预测 + R)
④ x更新 = x预测 + K × (z − x预测)
⑤ P更新 = (1 − K) × P预测

第一步先沿用旧压力；第二步承认这段时间压力可能变化；第三步决定新测量占几成；第四步修正压力；第五步更新估计的不确定性。

代入一次：预测压力 100 kPa，预测方差 16，新测量 110 kPa，R = 64。K = 16 / (16 + 64) = 0.2，所以输出 102 kPa，更新方差为 12.8 kPa²。这里的 16 已是预测方差，不再重复加 Q。

还想看懂为什么 K 恰好是 0.2？打开单独的互动讲解。

适用场景

有连续压力测量，能对传感器噪声和压力变化程度做出合理估计；希望把“预测”和“测量”系统地结合。例如压力缓慢变化、读数带有随机噪声的场景，可以用这个一维模型作为起点。

实际效果与代价

  • 固定 R，增大 Q：更承认压力会变化，通常更快跟随，也可能更抖。
  • 固定预测方差，增大 R：更不信任测量，新读数的影响减小。
  • 模型和 Q、R 合适时，能在抑噪与跟踪之间取得较好的折中；不是“自动调到最好”。
  • 当前模型不包含变化速度，也不会自动识别尖峰。快速、有规律的运动可能需要更合适的状态模型。
  • Q、R 固定、连续更新足够久后，K 通常趋于稳定，表现会接近固定权重的指数平滑。

1. 先明确目标：我们究竟想控制什么？

视频启发的入门 · 待学习

一辆车希望保持 60 km/h，前方却开始上坡。坡度改变了车受到的阻力，原来的油门位置未必还能维持原来的速度。控制要解决的问题是：环境在变，怎样让关心的量仍接近目标？

r：设定值，也就是目标
希望车速达到 60 km/h。它说的是“想要多少”。
y：输出，也就是实际结果
例如速度表读到 56 km/h。它说的是“现在多少”。
d：扰动，外来的影响
例如坡度、风和负载变化。它不是控制器主动发出的命令。
u：控制量，可以调整的动作
例如油门或驱动力指令。它与车速不是同一个物理量，单位也未必相同。

“保持不动”也需要控制。倒立摆要立住，无人机要在风里悬停，船要抵住水流保持位置，往往都得持续调整作用力。表面上没移动，不代表内部没有动作。

把同一个问题放进另外四个场景
路灯照明
目标与实测量：地面照度。扰动：自然光变化。可调动作：灯的发光强度。
传送带
目标与实测量：电机或驱动轴转速。扰动：搬运负载变化。可调动作：电机驱动或转矩指令。r/min 是每分钟转数，不能当作 m/min 的线速度。
船舶定位
目标与实测量：位置。扰动：水流等外力。可调动作：推进器推力。这里讨论位置保持，不只是航向。
无人机悬停
目标与实测量：位置和姿态。扰动：风等外力。可调动作：各旋翼推力。

这些角色按入门模型划分；“可调动作”是帮助理解的物理补充，具体硬件与建模边界还要另行说明。

待练习 1：60 km/h、56 km/h、上坡，各是什么角色？

先自己说一遍，再核对：60 km/h 是设定值 r；56 km/h 是当前输出 y 的测量值；上坡带来的负载变化是扰动 d。目标速度本身不是扰动。

2. 看、比、调：反馈怎样形成一个环？

视频启发的入门 · 待学习

驾驶员看速度表，把实际速度和目标比较，再调整油门。油门又改变车速，新的读数再次回到驾驶员那里。结果会影响后续动作，这就形成了反馈。

看：读车速比：离目标多远调：改变驱动力再看新车速

最简单的单位负反馈中，误差 e就是“目标减实际值”。t 表示时间，r(t)、y(t) 表示这些量可以随时间变化。

e(t) = r(t) − y(t)
60 − 56 = +4 km/h；60 − 63 = −3 km/h

正常的定速控制方向下，+4 km/h 提示需要增加驱动力，−3 km/h 提示应减少驱动力。控制器把速度误差变成油门、力或转矩指令，而不是直接把“4 km/h”当作油门大小。

  • 开环：只按预先指令动作，不利用被控制输出的测量值修正。例如只按固定时间表开灯。
  • 闭环：把输出测回来，据此调整。例如测量地面照度，再调灯光以接近目标。

“自动”不等于“闭环”。自动执行固定程序也可能是开环。仅测天光并开灯，不等于对地面照度形成闭环；要看测量的是什么、反馈回到哪里。“负反馈”的负号指比较时减去反馈量，不是读数必须小于零，也不保证任意增益、延迟下都稳定。

待练习 2：按定时加热与按温度读数调节，谁对温度闭环？

根据温度读数调整加热的装置形成温度闭环。只按时间加热、完全不测温度的装置可以自动运行，但在这个描述中没有温度反馈。

3. 把驾驶员换成机器：谁看、谁算、谁动？

视频启发的入门 · 待学习
  • 传感器负责看：把实际输出变成可以使用的测量值，例如测车速。
  • 比较环节负责比：由目标与反馈量求误差；可以独立画成求和点，也可以在控制器内部。
  • 控制器负责算：根据误差和控制规律，算出下一步指令。
  • 执行器负责动：把指令变成物理作用，例如电机转矩、阀门开度、推进器推力。
  • 被控对象接受作用：例如车辆、电机与负载，产生我们关心的输出。
目标比较控制器执行器与对象输出传感器回到比较处

扰动要画在它实际起作用的位置。例如坡度通过车辆受力影响车速，不能一律画成新的目标输入。接下来用 P(s) 表示从控制器输出到系统输出的模型，按需要把执行器与物理对象一起包含进去。

控制器收到的是有误差和噪声的测量值，不是无误差的真实世界。还要考虑执行器上限、延迟、安全边界和故障处理。

为什么路灯有时怎么调也到不了目标？

灯只能增加照度，不能用“负的灯光”抵消阳光。如果自然光已经超过目标，关灯也未必能把总照度降到目标。这是执行器能力有限，不是把增益调大就能解决的问题。

待练习 3：速度传感器、电机驱动器、新放上的重物分别是谁？

依次是传感器、执行器／驱动环节、引起负载变化的扰动来源。实际设备的建模边界可以不同，先声明边界再分类。

4. 从反馈环，推到闭环传递函数

补充推导 · 待学习

前面讲的是“谁影响谁”。现在把同一条关系写成代数式，先限定为连续时间的单输入单输出系统。传递函数记录输入到输出的动态关系；把时间信号做拉普拉斯变换后，微分关系可以化成代数关系。小写 r、e、u、y 是时间信号，大写 R、E、U、Y 是它们的变换。本节 C 是控制器，P 是被控对象模型。

先把负反馈关系写对

目标 r误差 e = r − y控制器 C被控对象 P输出 y 反馈比较
E = R − Y，U = CE，Y = PU
T(s) = Y(s) / R(s) = P(s)C(s) / [1 + P(s)C(s)]

这个式子采用单位负反馈、单输入单输出 LTI 模型和零初始条件，先不计外加扰动；目标与反馈输出要在同一量纲下比较。PC 是环路传递函数。若传感器还有动态或比例 F(s)，分母相应变成 1 + PCF，不能原样套用。

这里的 P 表示被控对象（plant），不是卡尔曼中的估计误差方差 P；控制器 C 也不是傅里叶系数 C(f)。看公式时先认清本节定义。

导读算例：比例控制可以变快，也可能留误差

先看一个归一化的理想一阶对象 P(s) = 1 / (0.5s + 1)，只用比例控制 C(s) = 2，采用上述单位负反馈。

T(s) = 2 / (0.5s + 3)
单位阶跃目标下：y(t) = ⅔(1 − e−6t)
  1. 响应时间：闭环时间常数为 1/6 s，小于原对象的 0.5 s。
  2. 最终输出：目标为 1，输出却趋近 2/3，稳态误差为 1/3。
  3. 能得出的结论：这一模型里，单靠当前比例增益没有消除阶跃稳态误差；这不是“所有比例控制都有相同误差”的结论。

真实电机还有限流、摩擦、负载变化与采样延迟。上面的数字用来读懂模型，不是可以直接写进硬件的参数建议。

“单位阶跃”是目标在 t = 0 从 0 突然变成 1，之后保持；“归一化”是先把输出按选定基准缩放成无量纲量。这些数字不是一台真实电机的 rpm 或电压。算例以秒计时，指数 −6t 中的 6 对应 6 s⁻¹。

把中间两步也写出来，别只背分母
Y = PC(R − Y)
Y + PCY = PCR
(1 + PC)Y = PCR
T = Y/R = PC/(1 + PC)

传感器若用 F(s) 表示，则 E = R − FY，因而 T = PC/(1 + PCF)。F 的作用还包括把测量反馈换算到可与目标比较的量纲。F ≠ 1 时，比较点误差 R − FY 和输出跟踪误差 R − Y 不能混为一谈。反馈改变了闭环分母，因此不能直接拿开环对象 P 的分母当作闭环稳定性的答案。

对上面的算例，把 T = 2/(0.5s + 3) 的分母设为零，得到 0.5s + 3 = 0，根为 s = −6。这连接到下一节要学的特征方程。

待练习 4：换成 P = 1/(s + 1)、C = 9，最终能到 1 吗？

仍采用单位负反馈和零初始条件。T = 9/(s + 10)，根为 −10 s⁻¹；单位阶跃响应 y(t) = 0.9(1 − e−10t)，最终为 0.9，稳态误差为 0.1。这个理想模型更快、误差更小，不能推出真实系统的增益越大永远越好。

5. 特征方程为什么能告诉我们“会不会停稳”？

补充推导 · 待学习

想象把弹簧上的小车拉开再松手：有的慢慢停住，有的来回晃着停住。先不考虑持续施加的新输入，研究系统自己怎样动，这部分叫自然响应。

一个二阶线性模型的自然响应可以写成下面的微分方程。y′ 是变化速度，y″ 是变化速度的变化，a₁、a₀ 是由模型决定的系数。

y″(t) + a₁y′(t) + a₀y(t) = 0

为什么试 y(t) = est？因为指数函数求导后仍是自身乘一个数，能把“求导”转换成“乘 s”。这里 s 可以是复数，量纲为时间的倒数；若 t 用秒，a₁ 的单位为 s⁻¹、a₀ 为 s⁻²。

y = est，y′ = sest，y″ = s²est
(s² + a₁s + a₀)est = 0
s² + a₁s + a₀ = 0

指数项不为零，前面的多项式只能等于零。这就是特征方程。它的根告诉我们，哪些指数变化模式能够出现在自然响应里。

  • s = −2：出现 e−2t，时间越久越小，是衰减。
  • s = +1：出现 et，时间越久越大，是增长。
  • s = −1 ± j2：实数响应由 e−tcos(2t) 与 e−tsin(2t) 组合。外层 e−t让振幅衰减，里面的正弦／余弦让它来回振荡。j 满足 j² = −1。

把根画在复平面上，横轴是实部，决定衰减还是增长；纵轴是虚部，其绝对值对应振荡角频率。上面三个数值例子均按秒计时。

对有限维连续时间线性系统，全部内部模式的实部严格小于零，才会渐近稳定，也就是小偏差最终衰减到零。特征方程不单独决定完整输出：输入、初始条件、分子和零点也会影响具体幅值与最终值。

稍后再分清：特征根、极点，以及虚轴这个边界

极点是约简后传递函数分母的根；在没有隐藏模式的模型中，它们与相应动态模式对应。某些分子与分母因子相消，会把内部动态从这条输入输出关系里隐藏掉；所以内部稳定性不能只看约简后的分母。

BIBO 稳定的意思是“任何有界输入，都产生有界输出”。对适当的有理因果连续时间 LTI 传递函数，所有极点严格在左半平面才满足它。虚轴上的根要单独分析：理想无阻尼二阶系统会持续振荡，且不满足 BIBO 稳定；重复虚轴根还可能带来随时间增长的项。

待练习 5：s² + 4s + 13 = 0，会衰减振荡还是发散振荡？

根为 −2 ± j3，是衰减振荡。包络按 e−2t衰减，振荡角频率为 3 rad/s。先看实部的符号，再看虚部是否为零。

6. 二阶系统：把根的位置和曲线对起来

补充推导 · 待学习

弹簧小车给了我们两种直觉：它本来有多快，以及有多强的“止晃”作用。标准二阶模型用自然角频率 ωₙ和阻尼比 ζ来描述这两方面。它们读作 omega 下标 n、zeta。

T(s) = ωₙ² / (s² + 2ζωₙs + ωₙ²)
特征方程：s² + 2ζωₙs + ωₙ² = 0
  • ωₙ > 0：无阻尼自然角频率，单位 rad/s；不是一般阻尼下的实际振荡频率。
  • ζ ≥ 0：阻尼比，无单位。先在这里讨论常见的非负范围。
  • 模型前提：连续时间 LTI、没有零点、直流增益为 1。直流增益表示恒定输入对应的比例；当 ζ > 0 稳定时，单位阶跃的最终值为 1。下面的阶跃曲线都取零初始条件。
由二次方程，得到根与实际振荡频率
s₁,₂ = −ζωₙ ± ωₙ√(ζ² − 1)
当 0 < ζ < 1：s₁,₂ = −ζωₙ ± jωₙ√(1 − ζ²)
ωd = ωₙ√(1 − ζ²)

ωd 是欠阻尼时的实际振荡角频率。实部 −ζωₙ 控制衰减包络，虚部 ±ωd 对应振荡。若要换成 Hz，用 fd = ωd/(2π)。

下面固定 ωₙ = 2 rad/s，只改变 ζ。先看左图的根，再看右图的输出是否越过目标、振荡是否消失。曲线由模型计算，不是视频画面的测量数据。

  • ζ = 0 · 无阻尼 · 长虚线
    根为 ±j2，在虚轴上；阶跃响应 1 − cos(2t) 持续振荡。它不渐近稳定，也不满足 BIBO 稳定。
  • ζ = 0.5 · 欠阻尼 · 实线
    根为 −1 ± j1.732，在左半平面；输出会超出目标，然后振荡着靠近 1。
  • ζ = 1 · 临界阻尼 · 短虚线
    根为 −2 的二重根；标准模型的阶跃响应不振荡。固定 ωₙ 时，它是无振荡响应的最快边界，并不是所有性能指标下都最快。
  • ζ = 1.5 · 过阻尼 · 点划线
    根约为 −0.764、−5.236，都是负实根；标准模型的阶跃响应不振荡，较慢的根让尾段拖长。

完整算一次：T(s) = 4/(s² + 2s + 4)

对照系数：ωₙ² = 4，所以 ωₙ = 2 rad/s；2ζωₙ = 2，所以 ζ = 0.5。根为 −1 ± j√3，恰好对应图中的青色实线。

y(t) = 1 − e−t[cos(√3t) + (1/√3)sin(√3t)]
ωd = √3 ≈ 1.732 rad/s

超调百分比是输出最高峰超过最终值的部分，再除以最终值，以百分比表示；本标准模型的最高峰就是首次峰值。2% 调节时间是进入并持续留在最终值 ±2% 误差带所需的时间。

Mp = 100% × exp[−πζ/√(1 − ζ²)] ≈ 16.30%
首次峰值时刻 tp = π/ωd ≈ 1.814 s
峰值 ≈ 1.163；常用估计 ts ≈ 4/(ζωₙ) = 4 s

上面的超调与峰值时刻公式用于 0 < ζ < 1 的标准模型；调节时间 4 s 是常见工程近似，不能当作精确值。输入、初始条件或零点改变时，都要重新检查适用条件。

待练习 6：s² + 6s + 9 = 0 的 ωₙ、ζ 和根是多少？

ωₙ = 3 rad/s；2ζωₙ = 6，因此 ζ = 1；根为 −3 s⁻¹ 的二重根。它位于临界阻尼边界。

7. 稳、准、快要分开看：增益越大越好吗？

补充练习 · 待学习
  • 稳：偏差会不会自行放大？先检查闭环内部模式或相应极点。
  • 准：足够久后，输出离目标多远？第 4 节已经给出“稳定但有误差”的例子。
  • 快：多久到目标附近？有没有超调和明显振荡？
  • 抗扰动：负载、风或水流变化后能否恢复？恢复多近、需要多久？
  • 做得到：控制量有没有超过执行器上限？是否过度放大传感器噪声？

用另一个归一化教学模型来检验“增益越大越好”。令 P(s) = 1/[s(s + 2)]，比例控制 C(s) = K，K > 0，单位负反馈。这里按秒计时，K 是数值化模型里的增益参数，不是可以直接输入硬件的旋钮刻度。

T(s) = K / (s² + 2s + K)
ωₙ = √K，ζ = 1/√K
  • K = 1：分母为 (s + 1)²，根是 −1 的二重根，临界阻尼。
  • K = 4：根为 −1 ± j√3，ζ = 0.5，单位阶跃超调约 16.3%。
  • K = 9：根为 −1 ± j√8，ζ = 1/3，单位阶跃超调约 32.9%。

这三种情况下，增益变大让振荡和超调发生变化，根的实部却仍是 −1。不能说“根都更靠左，所以一切都更好”。在这个理想模型中它们都稳定，也不代表真实对象的任意增益都安全。

这些公式是理想化练习模型，不是视频里汽车、船或无人机的辨识结果。先把模型假设、单位与评价指标说清楚，再讨论调参。

待练习 7：“有负反馈就稳定，稳定就零误差”错在哪里？

第一处：负反馈系统的整体动态还取决于对象、增益、延迟等，负号本身不能证明稳定。第二处：稳定只回答相关响应是否有界、偏差模式是否衰减等问题，不自动保证目标跟踪无稳态误差；第 4 节的一阶比例控制就是反例。

认识 PID 三项：现在、累积、变化速度

先用理想连续时间的并联形式认识含义，积分初值取零：

u(t) = Kpe(t) + Ki∫₀ᵗ e(λ)dλ + Kdde(t)/dt
  • P 比例：看现在误差有多大。
  • I 积分：累积过去的误差；在稳定、未饱和且对象等条件适当时，可消除某些稳态误差。
  • D 微分：看误差变化有多快；它会对高频测量噪声敏感，实际常使用带滤波的微分项。

例如 e 用 rpm，u 用 0～1 的 PWM 占空比：Kp 的单位是占空比/rpm，Ki 是占空比/(rpm·s)，Kd 是占空比·s/rpm。若 Kp = 0.002/rpm，误差为 10 rpm，仅 P 项给出的占空比为 0.02，也就是 2 个百分点。

离散实现要把采样周期计入积分和微分，还要处理输出饱和、积分抗饱和与启动状态。不同 PID 参数形式不能只按参数名字照搬。

输入变了，输出会变多少、跟多快？

传感器、RC 低通和电机都会改变输入的大小与时间形状。传递函数把这种输入到输出的动态关系写成一个便于计算的模型。它描述系统，不是某一次波形的名字。

先备知识
输入 / 输出、曲线斜率、指数衰减；拉普拉斯与 Z 变换先认识用途，推导按需补上。
工程用途

先认清这对表达式

连续时间：H(s) = Y(s) / U(s)
离散时间：H(z) = Y(z) / U(z)

这里限定线性时不变（LTI）、零初始条件的输入输出关系：线性表示输入的加法与倍数关系可以传到输出；时不变表示同样输入晚一点施加，响应只晚一点出现。U、Y 是输入和输出经过对应变换后的表达，不是直接拿某时刻的 y 除以 u。

H(s) 用于连续时间模型；H(z) 用于按采样更新的模型，必须知道采样周期。两者不能只靠把字母 s 换成 z 得到。有初始储能或初始状态时，总响应还要计入初始条件。

导读算例：2 V 输入，RC 为什么只到 1.26 V？

理想一阶 RC 低通，时间常数 τ = RC = 0.2 s，初始输出为 0 V；t = 0 时输入从 0 跳到 2 V 并保持。

0.2 dy/dt + y = u
H(s) = 1 / (0.2s + 1)
y(t) = 2(1 − e−t/0.2) V，t ≥ 0
  1. 看最终值：保持 2 V 输入足够久，输出趋近 2 V。
  2. 看一个时间常数：t = 0.2 s，输出约为 2 × 0.632 = 1.26 V。
  3. 再看三个时间常数：t = 0.6 s，输出约 1.90 V，还没有严格等于 2 V。

这段慢响应来自模型中的储能过程。对于这个模型，τ 越大，跟随越慢；不需要先手算一遍积分，就能读出工程含义。

再往前一点：从 EMA 看到 H(z)

取固定系数 α = 0.2，输入记作 u[n]，输出为 y[n]，并令采样前状态 y[−1] = 0：

y[n] = 0.2u[n] + 0.8y[n−1]
H(z) = 0.2 / (1 − 0.8z−1)

z⁻¹ 表示延迟一拍。若输入从第 0 拍起为 1，前三个输出依次是 0.2、0.36、0.488。公式描述“每拍怎么变”；每拍究竟有多长，仍取决于采样周期。

这能接回卡尔曼与 EMA 的联系：只有增益固定等条件成立时，相关更新才可当作固定系数 EMA 分析；增益随时间改变的滤波过程，不能直接套一个固定的 LTI 传递函数。

频点 fk = kfs / N，频点间隔 Δf = fs / N
奈奎斯特频率 fN = fs / 2

fs 是每秒采样点数，N 是本次分析的点数，k 是频点编号。对均匀采样的实数信号，常画 0 到 fs/2 的单边谱；偶数 N 才恰好有奈奎斯特频点。Δf 是频率格子的间隔，不直接等于分开两个相邻峰的实际能力，还受窗形、信噪比等影响。

采样前先考虑抗混叠：普通基带测量中，要让保留的频率低于 fs/2，并按模拟滤波器的过渡带与所需衰减留出余量。采样后才做数字低通，通常无法把已混叠进来的成分重新分开。

导读算例：50 Hz、3 kPa，FFT 应该读到什么？

假设只有 x[n] = 3 cos(2π·50n/1000) kPa，无直流、无噪声，fs = 1000 Hz，N = 1000；采用未归一化的 DFT，不加窗（等效矩形窗）。

  1. 记录长度：Trec = 1 s；Δf = 1 Hz；奈奎斯特频率为 500 Hz。
  2. 峰的位置：50 Hz 落在 k = 50，记录里恰好包含 50 个周期。
  3. 峰的幅值：|X[50]| = 1500；单边峰值振幅 A = 2|X[50]|/N = 3 kPa。

若改成 50.5 Hz，1 秒内不是整数周期，能量会分散到多个频点，不能把最高一格的读数直接当作准确振幅。若模拟输入含 700 Hz，按 1000 Hz 采样会折叠到 300 Hz；这就是采样前抗混叠重要的原因。

窗与泄漏：为什么换窗以后峰也变了？

DFT 分析的是有限一段数据。截断相当于乘上窗，通常会使谱能量向附近频率扩散。Hann 等窗可以压低远处旁瓣，但同时拓宽主瓣，改变峰高；它们不是“消除所有泄漏”的开关。

加窗后先算 Xw[k] = DFT{x[n]w[n]}。对落在频点上的孤立实数正弦，在正负频率主瓣不互相干扰等条件下，单边峰值振幅常按下式校正：

A ≈ 2|Xw[k]| / Σw[n]

直流与偶数 N 的奈奎斯特频点不乘 2。非整频点正弦还可能有栅栏效应，不能只用这条校正保证最高格准确。补零可以把显示的频率网格变密，却没有增加记录信息或真正的分辨能力。

振幅谱与 PSD：看峰值，还是看一段频带的噪声？

振幅谱用于读正弦分量的大小，单位可为 kPa 或 V，并需注明峰值还是 RMS。功率谱密度（PSD）表示每单位频率的均方贡献，压力信号的单位是 kPa²/Hz；这里的“功率”不必是以瓦特计的物理功率。

采用上述 DFT 约定，窗为实数 w[n]，均匀采样、偶数 N 时，一个单边周期图 PSD 估计在内部正频点的归一化是：

Sxx[k] = 2|Xw[k]|² / (fs Σw[n]²)
频带均方贡献 ≈ Σ该频带Sxx[k] Δf

直流和奈奎斯特项仍不乘 2。PSD 校正使用窗的平方和，不能直接套用振幅谱的窗和。对去均值后的噪声，频带积分可估计该频带的方差；Welch 方法再通过分段平均降低估计起伏，代价包括可用分辨能力的变化。
