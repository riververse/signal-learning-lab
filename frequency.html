你想留下哪一种变化？

先把压力分成慢变化、中速振动和快速抖动，再看滤波器分别留下多少。

01 / 同一段信号，换一种筛选方式

横轴是秒，纵轴是相对基准压力的变化量（kPa）。每秒采样 100 次。三种成分的输入幅度各为 1 kPa，图中显示稳态结果，省略刚启动的过渡过程。纵轴固定，避免放大后误以为信号没有衰减。

每种成分，还剩下多少？

所有频率的保留比例

保留比例 1 = 幅度不变；0.5 = 幅度剩一半。曲线有缓坡，不是过了边界就突然消失。这里的比例指幅度，不是功率。50 Hz 是本例采样率的一半，也是频率图的上限。

02 / 把实验接到工作里

“高频”不等于“噪声”

  • 低通：保留慢变化、削弱快变化。例：让缓慢压力或温度显示更稳定；代价是快速冲击和响应速度可能损失。
  • 高通：削弱基线和慢漂移，突出快速变化。例：从压力信号里看振动；输出不再代表完整的绝对压力。
  • 带通：重点保留某一频率范围。例：观察某段机械振动；频段外的真实变化也会被削弱。

频率 f 表示每秒重复多少次，单位 Hz。0.5 Hz 是两秒一圈，20 Hz 是一秒二十圈。该不该去掉它，取决于你要测什么，不能只看它快不快。

截止频率是什么意思？

本页单独的低通或高通，在截止频率处，输出幅度约剩输入的 0.707 倍，这也叫 −3 dB 点。它不是“完全截断”的位置。带通由一段高通和一段低通串联，两个滑块标的是各段的截止频率，不是整个带通精确的 −3 dB 边界；串联后幅度会相乘，最高点通常也小于 1。

03 / 系数到底是什么？

窗口长度，和每个样本的权重是两回事

FIR 把有限个输入样本乘上各自的系数，再相加。M 是样本数量，b₀、b₁… 才是系数。

y[n] = b₀x[n] + b₁x[n−1] + … + b₍M−1₎x[n−M+1]

n 是第几次采样，x 是输入，y 是输出。两个滤波器都只用 2 个样本，却可以干不同的事：

系数 [0.5, 0.5]

当前值与上次值取平均。相邻读数相近时会保留；正负交替时会抵消。偏向低通。

系数 [0.5, −0.5]

当前值减去上次值，再除以 2。恒定输入会变成 0；正负交替会保留。偏向高通。

只有“等权滑动平均”这一种 FIR，系数才全部等于 1/M。窗口变大不能描述所有 FIR 的设计。滑动平均第一个完全抵消的频率为 Fs/M（M ≥ 2）；这也不是截止频率。它在其他频段还可能有残留。

IIR 也不只有一个 α

一阶指数平滑可以只用 α 调节，是 IIR 的一个简单例子。更一般的 IIR 同时使用输入的系数和过去输出的系数。下面展开当前实验实际使用的公式。

当前实验：由截止频率算出系数

Fs 是采样频率，fc 是这一段的截止频率，两者单位都是 Hz。要求 0 < fc < Fs/2。tan 是正切函数，π 约等于 3.14159，角度用弧度。

k = tan(π × fc / Fs)
r = (1 − k) / (1 + k)
低通：g = k / (1 + k)
y[n] = r y[n−1] + g x[n] + g x[n−1]

高通：g = 1 / (1 + k)
y[n] = r y[n−1] + g x[n] − g x[n−1]

这些是一阶 Butterworth 滤波器的数字实现，使用双线性变换并校准截止频率。它们和首页的指数平滑不是同一个公式。带通把高通的输出再送进低通。

如果我只想继续用首页的 α 呢？
对 y[n] = α x[n] + (1−α)y[n−1]，给定数字截止频率 fc，可以精确计算：
d = 2 sin²(π × fc / Fs)
α = √(d² + 2d) − d
sin 是正弦，√ 是开平方。常见的 α = 1 − exp(−2πfc/Fs) 是另一种按模拟衰减速度匹配的方法，只有 fc 远小于 Fs 时，其截止频率才近似吻合。不要混用这两种关系。
α 很大时，指数平滑在 0 到 Fs/2 内甚至没有 −3 dB 交点；α = 1 就直接输出输入。公式和物理频率都离不开采样率：每秒采样次数改变，原系数对应的 Hz 也会改变。


04 / 检查是不是真的理解了
两个 FIR 都取 2 个样本，效果就一样吗？
再想一下：采样率加倍，系数不变，会怎样？
相同的离散算法按“样本数”观察不变，但每个样本间隔变短。按 Hz 观察，对应的截止频率也会加倍。要保留同一个实际频段，需要用新采样率重新算系数。
