待学习 · 硬件实现专题

滤波，可以交给谁来做？

电阻电容能滤波，MCU 能算 FIR / IIR，专用数字电路也能算。同一个“滤波”，先看它在采样前，还是采样后。

从已有的 IIR / FIR 直觉出发，沿着传感器到程序的数据路走一遍。这里新增的是学习材料，不是完成记录；无需先买板卡。

分清分类沿采集链看抗混叠实验算法怎样落地外设与器件起步与检查
01

四个问题，不要挤在一个分类里

“巴特沃斯低通 IIR，跑在 MCU 上”这句话，可以同时成立。

处理什么信号？
模拟 / 数字

RC、运放直接处理连续电压；数字滤波处理一拍一拍的数值。

保留哪些频率？
低通 / 高通 / 带通 / 陷波

这是频率选择目标，与是不是硬件、有没有反馈不是同一问题。

响应与结构是什么？
响应族 ≠ FIR / IIR

Butterworth、Chebyshev 是响应设计家族，可用于模拟滤波器，也可导出数字 IIR。FIR / IIR 按离散冲激响应是否有限分类。并非每个 IIR 都属于这些命名家族。

谁执行它？
电路 / CPU / 专用逻辑

Sallen-Key、MFB 是模拟电路拓扑；CPU 软件、FMAC、FPGA 是数字实现路线。滤波算法不因从 C 代码搬进 FPGA 就变成模拟滤波。

RC 是不是 IIR？

理想一阶 RC 的冲激响应是指数衰减，理论上有无限长尾巴，可以建立“记忆逐渐衰减”的类比。但 RC 是连续时间系统，通常用 H(s) 描述；这里的数字 IIR 用离散差分方程与 H(z) 描述。两者的系数不能直接照抄，离散化方式与采样周期都要说明。[1]

继续区分：巴特沃斯、切比雪夫 I / II 的响应取舍。Chebyshev I 的纹波在通带，II 型的纹波在阻带。

02

先看采集链，再决定滤波放哪里

算法可以很漂亮，但 ADC 前丢掉的信息，程序拿不到。

  1. 传感器 / 模拟前端量程、偏置、放大、保护
  2. 模拟限带抗混叠、衰减带外干扰
  3. MUX / ADC 输入切换、驱动、采样保持建立
  4. ADC / 数字接口得到样本或调制比特流
  5. 数字滤波 / 降采样平滑、选频、改变输出速率
  6. 估计 / 控制 / 显示最终带宽与延迟预算

这是常见采集链的功能示意，不是通用接线图。模拟滤波、缓冲与 MUX 的实际顺序取决于电路；ΣΔ ADC 内部还会包含调制、数字滤波与抽取。

ADC 前：让不该进入的频率先变小

常见做法是无源 RC，或运放构成的有源滤波器。RC 便宜直观，但滚降有限且会加载信号源；有源滤波可以隔离负载、获得更高阶响应，也受运放带宽、噪声、摆幅和稳定性限制。

理想无负载一阶 RC：fc = 1 / (2πRC)。例如 R = 1 kΩ、C = 1 µF，时间常数 τ = 1 ms，fc ≈ 159 Hz。真实 ADC 输入不是无限大阻抗，不能只用这一个公式定值。[1][2]

ADC 后：数字算法做更灵活的选择

CPU、DSP 指令、数字外设和 FPGA 都可以处理采样值。改系数比较方便，响应也更容易重复；代价是计算、存储、量化和延迟。

数字滤波能压低仍可区分的带外成分，不能普遍恢复已经混叠到目标频段的信息，也不能消除前级饱和失真。降采样前还要先限带，否则会在新的采样率处再次混叠。[2][3]

MUX 后放一个大电容，为什么可能串台？

切到新通道后，电容仍带着上一通道的电压；信号源、开关、缓冲器与 ADC 采样电容都需要建立时间。把共享 RC 的截止降得很低，可能让新的电压更来不及稳定。[2]

理想单极点、满量程阶跃的教学估算：残留误差按 e−t/τ 衰减。若要求小于 12 位 ADC 的半个 LSB，需 t > ln(8192)τ ≈ 9.01τ。这不是某颗 ADC 的等待时间；真实设计应按具体数据手册、源阻抗和示波器测量决定。

检查每通道前端滤波、MUX 后缓冲/电荷桶、切换等待和 ADC acquisition time；不要用“后面再平均”掩盖建立误差。

03

实验：顺序换一下，结果为什么不同？

40 Hz 有效信号，混入 960 Hz 干扰；ADC 以 1000 samples/s 采样。

理想稳态合成模型 · 幅值归一化 · 不代表电路实测

960 Hz 混叠后40 Hz
干扰 / 有效信号幅度60.0%
有效信号剩余幅度1.000

960 Hz 在 1 kHz 采样下折叠到 40 Hz，与有效信号占据同一个数字频率。请先选数字 FIR，再试着加上 ADC 前的 RC。

怎么算的？模型包括什么、不包括什么？

输入为 cos(2π·40t) + 0.6cos(2π·960t)。每隔 1 ms 采样，960 Hz 与 −40 Hz 等价，实余弦表现为 40 Hz。数字线性滤波对重合的频率给予相同幅度增益，因此干扰/有效幅度比不会靠它改变。

RC 使用 H(f) = 1 / (1 + j f/fc) 的解析幅相响应；FIR 使用 8 个 1/8 系数；IIR 使用 y[n] = 0.2x[n] + 0.8y[n−1] 的稳态频响。显示值是各分量的幅度，不是混合曲线峰峰值。模拟 RC 会先分别衰减 40 与 960 Hz，也会改变相位。

模型不含启动瞬态、ADC 量化、噪声随机性、元件公差、运放限制、采样抖动或 MUX 建立过程。RC 只有衰减，不能“彻底消灭”所有混叠；真实阶数与截止要从信号带宽、干扰幅值和容许误差反推。

04

算法不变，把执行者换掉

FIR 记住若干输入；IIR 还使用反馈状态。寄存器、RAM 和变量都可以承担“记忆”。

y[n] = 0.25 × (x[n] + x[n−1] + x[n−2] + x[n−3])

初始状态为 0；输入仅在第 0 拍为 1。

CPU 用变量或数组保存状态，按指令完成乘法与加法。切换实现方式，不改变理想算法的输出。

FIR 的硬件长什么样？

样本先保存在移位寄存器或 RAM，每个历史样本乘一个系数，再求和。FPGA 可以并行做多个乘加，也可以让少量乘加单元在更高时钟下复用。并不是每个抽头都必须有独占乘法器。[6]

IIR 的反馈放在哪里？

上次输出或内部状态保存在寄存器/RAM，参与下一拍计算。FPGA 也能实现数字 IIR；反馈依赖让流水线和多通道调度更需要仔细安排。物理电路里有寄存器反馈，不会因此变成模拟 RC。

05

从 MCU 起步，再看专用硬件

先证明算法和采样条件对，再为明确的性能瓶颈换执行方式。

CPU / DSP 指令

最适合先建立可检查的基线

普通 MCU 也能用 C 运行 FIR / IIR。CMSIS-DSP 提供 FIR、biquad IIR、抽取等实现；DSP 指令与 FPU 能帮助运算，但仍由程序安排数据流。

  • 要付出 CPU 时间和状态内存
  • 按最坏情况测执行时间，不只看平均值
  • 先用浮点参考结果校验，再考虑定点
Arm 官方滤波函数 [3]

STM32G4 FMAC

专用的数字乘加滤波单元

AN5305 中的 FMAC 支持 FIR 和直接型 I 的 IIR，使用 16 位输入/系数与 26 位累加器，可配合 DMA。256 × 16 位本地存储由系数、状态和缓冲区共享，不能读成“支持 256 阶”。

  • 自己设计系数、缩放和缓冲区
  • 不是通用浮点 DSP
  • 有无此外设以具体料号为准
ST AN5305 [4]

STM32F7 DFSDM 示例

数字接口、Sinc 滤波与抽取

所链 F7 文档的 DFSDM 可处理外部 ΣΔ 调制器/PDM 数据，也支持并行数字数据；有 Sinc1–Sinc5、FastSinc 等选项。它与能装入一般 FIR/IIR 系数的 FMAC 不同。

  • 关注输入格式、抽取率、建立时间
  • 输出位数不等于有效测量精度
  • 不同 STM32 系列不可照搬外设能力
ST F7 外设培训 [5]

FPGA / 专用 DSP

为吞吐、并行和确定时序服务

FPGA 可把数字加权和做成流水线或复用 MAC；专用 DSP 则以适合信号运算的指令与存储结构执行程序。滤波器的数学目标仍然需要先确定。

  • 检查时钟、采样率、通道数与资源
  • 核对系数位宽、流水线与接口延迟
  • 换硬件不能抵消算法本身的延迟
AMD FIR Compiler [6]
查芯片时，别把品牌相似当成功能相同。

例如 GD32F303 可以先从 CPU / DSP 指令的软件实现入手；不能把 STM32G4 的 FMAC 或 STM32F7 的 DFSDM 能力直接套上去。请用具体料号的数据手册和参考手册核对。这里没有宣称某个 GD32F303 型号具备这些 ST 外设。GigaDevice 官方资料入口 [7]

其他滤波也能硬件实现吗？中值、CIC、卡尔曼怎么放？

中值是非线性排序/选择运算，CPU 和数字逻辑都能实现，不能用线性 FIR/IIR 的冲激响应分类概括它。CIC/Sinc 常用于多速率抽取/插值，关注通带下垂、字长增长和降采样前的抑制。卡尔曼属于模型与不确定性驱动的状态估计，也能在 CPU、DSP、FPGA 上实现，但不等同于换一组固定低通系数。

“能用硬件做”只是可实现性；是否值得，取决于通道数、速率、延迟、精度、资源和开发成本。

06

把三个常见场景，变成可验证的小任务

以下都是通用、假设性的练习，不代表某块实际硬件的参数。

慢变压力：先做一阶 IIR

先确认有效变化有多快、允许延迟多少。保留原始采样和时间戳，同时计算 y += α(x − y)。比较静态抖动和真实阶跃；不能只挑“最平”的曲线。

若器件内部已滤波，还要计入内部输出速率与建立延迟。板外 RC、器件数字滤波、软件低通可能同时存在。

磁编码器：先确认读到什么

模拟 sin/cos、数字角度、ABZ 脉冲是不同接口。模拟双通道需核对采样时间、增益和滤波相位的一致性；数字角度可能已带内部处理。

角度跨 359°→0°，不能直接做普通算术平均。先处理周期性/展开及真实转速约束，再评估滤波延迟对控制环的影响。滤波不能找回漏掉的整周。

14 路 MUX：每一路有自己的时间和状态

假设实际得到的总有效速率为 14 ksample/s，14 路均分才是每路 1 ksample/s；ADC 额定最大速率不等于这个有效速率。切换、建立、转换和丢弃样本都要计时。

各通道保留独立 FIR/IIR 状态，按通道顺序记录时间戳。同一扫描帧也不是同时采样；若每隔 1/14000 s 取一路，首末相差约 0.929 ms，相关计算可能需要补偿。

最小软件原型：14 路各自保留 IIR 状态
/* 教学核心，不含 ADC / DMA 驱动。ch 必须在 0..13。 */
#include <stdbool.h>
float filtered[14] = {0};
bool initialized[14] = {false};

float update_channel(unsigned ch, float sample, float alpha) {
    /* 调用前校验 ch < 14、0 < alpha && alpha <= 1、输入有限。 */
    if (!initialized[ch]) {
        filtered[ch] = sample;
        initialized[ch] = true;
    } else {
        filtered[ch] += alpha * (sample - filtered[ch]);
    }
    return filtered[ch];
}

首个读数初始化属于启动策略，与前面零状态冲激实验不同。真实代码要处理越界、异常值、并发和断流；不要让 14 路共用一个 y。α 的 Hz 含义取决于每路实际更新周期；不规则采样不能当成固定采样率。

定点先算一个小数，不急着把整套滤波搬过去

以有符号 Q15（1 个符号位、15 个小数位）为例：0.5 存成 16384，0.25 存成 8192。相乘的整数为 134217728，带 30 个小数位；缩回 Q15 后是 4096，代表 0.125。乘积不能先装回 16 位再求和。

实际实现还要定义舍入、饱和、累加器位宽和内部缩放。Q15 的最大正数略小于 1，不能把正 1 直接当成可表示的输入；负系数和反馈也可能让中间结果超出输入范围。先用浮点参考，再比较满量程、阶跃和零输入时的定点结果。[3][4]

再做一个运算量估算：14 路、每路 1 ksample/s、每路 32 抽头直接 FIR，名义上需要 14 × 1000 × 32 = 448000 次乘加/秒。它不等于 448000 个 CPU 周期，也不是某芯片的实测负载；数据搬运、实现结构和指令都要另算。

最后把四种代价放到一起

模拟与 ADC 建立
RC 时间常数、MUX 切换、采样保持、器件内部数字滤波。
算法响应
对称 N 抽头线性相位 FIR 的群延迟是 (N−1)/(2fs)。8 点平均、fs = 1 kHz 时为 3.5 ms。一般 IIR 的群延迟随频率变化，不是一个统一常数。
执行与搬运
运算时间、DMA 缓冲、块处理等待、总线和流水线延迟。算得更快，不代表滤波器更“跟手”。
定点与数值范围
系数缩放、乘积/累加位宽、舍入和饱和都要核对；IIR 还需检查量化后的稳定性与零输入极限环。二阶节常比单个高阶直接形式更好管理，但仍要验证。[3][4]
  1. 先写指标。每路采样率、有效带宽、噪声频带、允许误差和延迟。
  2. 先查采样链。防饱和、抗混叠、MUX/ADC 建立，确认原始数据可信。
  3. 先做软件基线。一阶 IIR 或小 FIR，保存原始/滤后数据和时间戳；用直流、阶跃、正弦与满量程输入检查。
  4. 再决定是否加速。测量 CPU 占用和最坏延迟，必要时再迁移 CMSIS-DSP、外设或 FPGA；与参考输出对比。
